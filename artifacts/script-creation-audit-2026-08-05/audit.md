# 剧本创作现状审计

审计对象：`http://localhost:8080/` 剧本创作功能  
审计日期：2026-08-05  
对照需求：`漫剧视频创作平台_PRD.md`

## 1. 审计范围

本次走查覆盖剧本创作入口、专业创作建项、上传文稿模式、项目创作工作台，并结合前端、后端现有实现核对六步 PRD 的可复用能力。

## 2. 流程步骤与健康度

| 步骤 | 现状 | 健康度 |
|---|---|---|
| 1. 剧本创作入口 | 提供快速、专业、上传、TVC 四种入口，层级清晰 | 一般 |
| 2. 专业创作建项 | 可选择短剧/长篇/TVC及来源方式，可创建项目 | 一般 |
| 3. 上传文稿模式 | 入口和选中态存在，但没有文件选择、解析进度和导入确认 | 阻断 |
| 4. 流程化创作台 | 有流程轨、版本、上下文和生成入口，但仍是旧八阶段文本工作流 | 较弱 |

## 3. 已确认优点

- 已有统一视觉变量、Element Plus 组件和桌面三栏工作台骨架，可继续复用。
- 后端已经存在上传解析、生成任务、内容版本、分镜和依赖关系等基础服务，不需要从零开始。
- 建项卡片具备键盘操作和 `radio` 语义，应用已有跳转主内容入口与全局焦点样式。
- 工作台已经具备保存状态、冲突提示、历史版本和创作上下文的初步结构。

## 4. 最高优先级问题

1. **入口与实际行为不一致**：`mode=upload` 路由参数未被建项页读取；点击“上传已有文稿”仍默认选中 AI 手动创作。
2. **上传功能未接入 UI**：选择“上传剧本”后仍显示故事种子文本框，没有文件选择、格式校验、解析状态和章节确认；后端已有相关 API。
3. **建项数据断链**：创建项目时提交的 `start_content` 未自动回填到工作台的故事种子编辑区。
4. **现有阶段与目标 PRD 不一致**：当前为故事种子、角色、梗概、大纲、正文、审核、内容去向、分镜；目标为上传、小说分析、改编方案、结构化剧本、剧本正文、文字分镜。
5. **生成结果过度文本化**：角色、梗概、大纲、正文均以单段纯文本展示，缺少事件、人物、世界观、节拍、场景、内容块和镜头字段的结构化编辑。
6. **生成门禁缺少可操作引导**：创作圣经未确认会阻断 AI 生成，但当前工作台只显示“尚未确认”，没有直接完成门禁的主按钮和原因说明。
7. **任务控制不完整**：前端生成请求没有复用统一鉴权请求层；取消能力虽存在于组合函数中，却没有工作台入口，且后端只允许取消 `pending` 任务。
8. **最近项目不可见**：建项后返回“剧本创作”，最近项目仍为空；前端对接口响应进行了多取一层 `data` 的解析。
9. **工作区过窄**：1280px 桌面下同时存在 232px 全局侧栏、220px 流程轨和 240px 上下文栏，核心编辑区仅余约 540px，不适合剧本与分镜编辑。
10. **无障碍风险**：流程轨步骤是不可聚焦的普通元素；部分上下文标签仅 11px，次要灰色文字存在对比度风险；状态变化主要依赖 toast，仍需键盘与读屏实测。

## 5. PRD 差距

| PRD 模块 | 当前支持度 | 主要缺口 |
|---|---|---|
| 小说上传 | 20% | 缺文件 UI、解析进度、章节范围和错误恢复 |
| 小说分析 | 25% | 只有角色/梗概入口，缺事件、人物详情、世界观和章节大纲结构 |
| 改编方案 | 15% | 旧版存在改编入口，但未接入当前工作台；缺高压场景和策略确认 |
| 结构化文字剧本 | 20% | 仅有通用大纲文本，缺集、节拍、时长和钩子结构 |
| 剧本正文 | 35% | 有正文生成和旧版文本编辑器，缺场景/内容块结构与一致性检查 |
| 文字分镜 | 45% | 已有专业分镜后端和编辑器，但当前工作台只展示轻量卡片，缺完整衔接和导出入口 |
