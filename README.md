## 本地端口约定

| 端口 | 服务 | 说明 |
|---|---|---|
| `3001` | new-api 管理端 | 基于 `QuantumNous/new-api` 完整源码，代码位于 [`new-api/`](new-api/) |
| `8080` | AICP 用户端 | 用户访问与正式验收入口 |
| `5173` | AICP 前端调试 | 仅用于 Vite 本地开发，不作为产品入口 |

### 双端账号与功能边界

- `8080` 与 `3001` 共用同一套平台账号身份，`user-svc` 是账号、密码、企业和角色信息的唯一事实源。
- `8080` 面向创作者和企业成员，提供漫剧生产、资产、交易、画布与协作功能。
- `3001` 面向平台管理员和运维人员，提供 new-api 渠道、模型、令牌、额度、计费和运行监控功能。
- new-api 可保存与平台用户一一对应的影子用户、分组和配额记录，但不得形成第二套独立注册、密码或企业身份体系。
- 当前仅完成端口、进程和数据目录隔离；统一登录与账号映射仍待实现。完成前，`3001` 的本地管理员账号只用于初始化和联调。

## 版本历史

| 版本 | 关键变更 |
|---|---|
| V1.0 | 第一周期MVP：用户、剧本资产工作台（AI样章/上传/章节编辑/故事圣经/分镜脚本、钩子策略、每集联合审核）、剧本仓库、画布项目、分镜卡片、导出 |
| V1.1 | 交易市场、AI资产市场、企业中心、生产SOP、权限审批 |
| V1.2 | 画布节点引擎（5节点）、脚本流水线、导演台、多模态参考、Agent雏形 |
| V1.3 | 无限画布（11节点类型）、下游菜单、全能参考视频、多副本并行、资产双向联动、工作流模板、Agent/Skill深度集成、SOP画布质检 |
| V1.5 | 产品定位升级为“工业化生产工作台”：剧本资产→分镜脚本Master→画布生产→节点→资产→批量生成→质检与采用版本→素材包导出→交易/授权→工作流→Agent/Skill。明确不提供视频剪辑、合成或多轨时间轴。 |
