## 版本历史

| 版本 | 关键变更 |
|---|---|
| V1.0 | 第一周期MVP：用户、剧本资产工作台（AI样章/上传/章节编辑/故事圣经/分镜脚本）、剧本仓库、画布项目、分镜卡片、导出 |
| V1.1 | 交易市场、AI资产市场、企业中心、生产SOP、权限审批 |
| V1.2 | 画布节点引擎（5节点）、脚本流水线、导演台、多模态参考、Agent雏形 |
| V1.3 | 无限画布（11节点类型）、下游菜单、全能参考视频、多副本并行、资产双向联动、工作流模板、Agent/Skill深度集成、SOP画布质检 |
| V1.5 | 产品定位升级为"工业化生产工作台"：剧本资产→分镜脚本Master→画布生产→节点→资产→批量生成→时间线→合成导出→交易/授权→工作流→Agent/Skill完整闭环。计费积分体系。 |
