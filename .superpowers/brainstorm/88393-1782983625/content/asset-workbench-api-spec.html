设计确认 3B/4：接口级详细契约

统一前缀 /api/v1；所有接口要求 JWT 和 X-Workspace-Id。API 边界使用 project_uuid / canvas_uuid / asset_uuid，数据库内部 ID 不暴露给页面。

1. 工作台查询接口

方法与路径输入响应 data
GET /assets/workbench/projectsscope=mine|workspace、keyword?、include_archived=falsescope、projects[]、special_collections、totals
GET /assets/history/recordsscope、project_uuid?、collection?、category?、status?、media_type?、model_id?、created_by?、created_from/to?、tags?、keyword?、sort、page、page_sizeitems[]、pagination、facets
GET /assets/history/records/{recordId}recordId=task:{uuid}|asset:{uuid}summary、task?、asset?、source、references[]、activities[]、allowed_actions

collection 枚举：unfiled、favorites、published、trash。status 枚举：pending、running、succeeded、failed、canceled。

接口请求体响应/规则

PUT /assets/{assetUuid}/favorite无幂等；返回 favorited=true
DELETE /assets/{assetUuid}/favorite无幂等；返回 favorited=false

operation：move、set_category、add_tags、remove_tags、trash、restore。

5. 任务命令：保留并收紧

POST /generation/tasks/{taskUuid}/cancel：仅 pending/running 且有项目权限；返回最终状态。
POST /generation/tasks/{taskUuid}/retry：仅 failed/canceled；请求体含 parameters_patch? 与 idempotency_key；返回新 task_uuid 和 retry_of_task_uuid。
GET /generation/tasks/{taskUuid}：补充 Workspace 校验，不再只凭 UUID 查询。

6. 错误码与 HTTP 状态

46101 资产不存在或不可见
46102 资产状态不允许操作
46103 资产文件缺失
46104 目标项目/画布不可用
46105 分类不合法
46106 发布流程冲突
46107 批量数量超限
46108 幂等键冲突
46109 数据版本冲突

HTTP 使用 400/403/404/409/422；ApiResponse.code 保留业务码。越权查询统一表现为 404，防止枚举其他 Workspace 资产。

7. 兼容策略

旧 GET /assets/history 保留一个版本周期，内部转调新 records 查询并返回旧列表格式，同时记录弃用日志；旧 POST /assets/{id}/send-to-canvas 若缺少目标画布则返回 422，不再假成功。前端全部切新 UUID 契约后再移除旧接口。
