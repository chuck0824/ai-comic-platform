设计确认 3A/4：页面级详细规格

主路由：/asset-history。页面状态全部映射到 URL，刷新、分享链接和浏览器前进后退都能恢复。

页面区域与字段

区域展示字段/控件行为
顶部范围栏我的资产、团队资产、全局搜索、视图切换、批量模式切换 scope 后清空失效项目；团队入口按权限显示
项目树project_id、项目名、封面、题材、资产数、进行中数、失败数；未归档、收藏、已发布、回收站支持按最近使用/名称排序；项目只做一级分库，不把题材当目录层级
资产分类全部、角色、场景、道具、分镜、配音、音乐、其他；每类显示数量分类字段使用 category，不依赖 image/video/audio 媒体类型
筛选栏keyword、status、media_type、model_id、created_by、created_from/to、tags、sort300ms 防抖；服务端查询；一键清空；展示已启用筛选数量
记录区网格/列表视图、总数、分页、每页 24/48/96、当前选择数请求竞态保护；加载骨架；空态区分无数据/无匹配/无权限/加载失败
详情抽屉预览、基础信息、生成参数、来源与引用、操作记录打开后 URL 写入 record_id；关闭后保留列表位置

记录卡片：按状态展示

pending / running

任务名、category、模型、创建人、排队位置或进度、已耗时、预计积分；操作：取消、查看参数。

failed / canceled

失败阶段、error_code、用户可读原因、失败时间；操作：重试、复制参数、移入回收站。取消记录默认折叠。

succeeded asset

缩略图/波形、名称、category、媒体类型、尺寸/时长、模型、创建人、时间、收藏/发布状态；操作：预览、画布、下载、更多。

详情抽屉字段

概览
asset_id / task_id、名称、项目、category、media_type、文件格式、大小、宽高、时长、创建人、创建/更新时间、标签、收藏、发布状态。
生成参数
provider、model_id、prompt、negative_prompt、seed、分辨率、帧率、时长、参考资产、原始 parameters JSON（折叠展示）。
来源与引用
来源画布/节点/分镜、重试来源、目标画布引用列表；可跳转到仍有权限访问的来源。
活动记录
创建、重命名、移动、收藏、发送画布、发布、删除、恢复；显示操作者与时间。

操作与弹窗精确定义

操作输入成功结果禁止条件
发送到画布目标项目、目标画布、放置方式创建节点，提供“留在此处/打开画布”回收站、文件缺失、无目标权限
再次生成复制原参数，可修改模型/Prompt新任务出现在同项目同分类顶部来源参数不可读、模型下线且未重新选择
移动/归档目标项目、目标 category更新归属并刷新两侧计数无目标项目编辑权限
发布市场标题、简介、标签、许可、预览图个人进入发布结果；团队生成审批单文件缺失、已删除、正在审批
删除确认；展示引用数量进入回收站并显示到期时间无删除权限、资产处于发布处理中

批量操作规则

同一 Workspace 内可批量移动、改分类、加/删标签、删除、恢复和下载；跨项目选择允许，但执行前逐项鉴权。部分失败时返回成功/失败明细，不整体伪装成功。发布市场不做批量，避免审批与元数据质量失控。

URL 参数

scope、project_id、category、status、media_type、model_id、created_by、from、to、tags、keyword、sort、page、page_size、view、record_id。
