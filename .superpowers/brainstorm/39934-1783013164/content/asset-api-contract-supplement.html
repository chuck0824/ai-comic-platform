接口契约补充：路径、字段、状态码与兼容规则

本页作为 3B 的补充，可直接约束 Controller、DTO、前端 API 和接口测试。

一、路径与协议统一规则

规则确定口径
资源路径复数名词 + kebab-case；命令使用子资源。列表 /assets/history/records，详情改为 /assets/history/records/{recordKind}/{recordUuid}，避免把 task:uuid 复合值塞进单个路径变量。
外部标识页面/API 只使用 asset_uuid、task_uuid、project_uuid、canvas_uuid、node_uuid；内部自增 ID 只用于表关联。
WorkspaceX-Workspace-Id 必填，1–64 字符；不允许请求体覆盖。scope=mine 仅附加 created_by=当前用户，scope=workspace 查询当前 Workspace 可见资产。
字段命名该模块 DTO 统一 snake_case；使用 DTO 级 @JsonNaming(SnakeCaseStrategy)，不修改 Jackson 全局策略，避免影响现有模块。
幂等创建类命令使用请求头 Idempotency-Key，1–64 字符，24 小时有效；同键同载荷重放原响应，同键不同载荷返回 409/48013。
并发控制修改/移动/删除/恢复使用 If-Match: "{row_version}"；响应返回 ETag。缺失返回 428，版本冲突返回 409/48004。
时间请求/响应使用 RFC 3339 UTC，例如 2026-07-03T04:20:00Z；前端按 Asia/Shanghai 展示。

二、查询参数类型与约束

分页
page: int，默认 1，最小 1
page_size: 24/48/96，默认 24，最大 100
非法值返回 400/40002
排序
sort: created_at:desc（默认）、created_at:asc、updated_at:desc、name:asc；白名单之外拒绝
搜索
keyword: trim 后 1–100 字符；搜索名称、Prompt、task_uuid、asset_uuid；特殊字符参数化查询，不拼 SQL
枚举
record_kind: task/asset
media_type: image/video/audio/other
category: character/scene/prop/storyboard/voice/music/other
状态
status 可逗号分隔，最多 5 个：pending/running/succeeded/failed/canceled；资产成功统一映射为 succeeded
日期与标签
created_from/to: RFC 3339，from ≤ to，范围最多 366 天
tags: 逗号分隔，最多 10 个，每项 1–32 字符，AND 匹配

三、请求字段精确定义

命令字段约束
PATCH /assets/{uuid}name 1–200；category 枚举；tags 最多 20 个、去重、每项 1–32。至少提交一个字段；禁止修改 media_type、file_url、owner。
POST /assets/{uuid}/movetarget_project_uuid nullable（null=未归档）；target_category 必填；目标必须属于当前 Workspace 且用户有编辑权。
POST /assets/batchasset_uuids 1–100、去重；operation 枚举；payload 随操作校验。每项独立事务，响应明确部分成功。
POST /assets/{uuid}/send-to-canvastarget_project_uuid、target_canvas_uuid 必填；placement 为 viewport_center/auto/absolute；absolute 时 x/y 必填且为有限数值。
POST /assets/{uuid}/regeneratemodel_id 1–100；prompt 最大 20,000；parameters_patch 最大 32KB，只允许模型注册表声明的参数；先执行积分预估。
POST /assets/{uuid}/publishtitle 1–120；description 1–2000；tags 1–10；license_code 必须来自市场字典；团队资产禁止 direct。

四、响应与状态枚举

统一外壳：{ code:int, message:string, data:object|null, request_id:string, timestamp:epoch_seconds }。列表 data 使用现有 PageResult：items + pagination{page,page_size,total,total_pages,has_more}，额外 facets 与 pagination 同级。

任务状态
PENDING → RUNNING → SUCCEEDED / FAILED
PENDING/RUNNING → CANCELED
终态不可原地回退；重试创建新任务
资产生命周期
ACTIVE → TRASHED → ACTIVE（恢复）
TRASHED 到期后物理清理文件和主记录，审计日志保留
发布状态
NONE / PENDING / APPROVED / REJECTED / CANCELLED
复用现有资产市场枚举，不新增同义状态

allowed_actions：后端返回 preview、edit、favorite、download、send_to_canvas、regenerate、publish、trash、restore、cancel_task、retry_task；前端不自行猜权限。

六、兼容与迁移规则

阶段 1：加字段与回填
只做 additive migration。workspace_id 按现有 owner/project 回填；category 按 sub_type 映射，无法识别归 other；favorite=1 迁入个人收藏表；默认 lifecycle=ACTIVE。
阶段 2：双写与影子校验
GenerationExecutor 同时写旧字段和新字段；新查询与旧查询做数量/归属抽样对比。禁止双写两套任务表，generation_tasks 是唯一资产任务源。
阶段 3：前端切换
新工作台切 records API；旧 /task-monitor 302/前端 redirect 到 /asset-history?status=pending,running,failed；旧侧栏入口移除。
阶段 4：弃用清理
旧 GET /assets/history 保留 2 个发布版本且至少 60 天，响应增加 Deprecation: true、Sunset、Link。调用量连续 14 天为 0 后移除。

发送画布特殊兼容：旧接口缺少 target_canvas_uuid 时返回 422 和迁移提示，绝不继续返回假成功。旧数字 assetId 仅在兼容 Controller 内解析，响应一律返回 UUID。回滚：新字段、双写和新读路径均由独立开关控制；回滚只切回旧读，不删除已写新字段。
