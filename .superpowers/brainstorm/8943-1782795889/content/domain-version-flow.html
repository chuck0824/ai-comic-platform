分镜领域模型与版本流

核心原则：Master 表示作品中的分镜资产；Version 是可审计版本；场景、镜头和辅助模块全部归属版本。

1领域实体

Storyboard Master

  • project_id / content_unit_id
  • 源正文版本
  • 当前草稿 / 当前锁定版本
  • 制作状态与生产准入

Storyboard Version

  • parent_version_id
  • A / B / C 档与版本号
  • draft / reviewing / locked
  • revision 乐观锁
  • 总镜头、总时长、schema_version

Scene + Shot

  • 场景稳定键与排序
  • 镜号、时长、景别
  • 13 维镜头字段
  • 角色 / 场景 / 资产引用
  • 逐镜确认状态

Professional Modules

  • 情绪区间与节拍
  • 图片 / 视频提示词模板
  • 类型修订与一致性规则
  • 人物视觉规范与镜头绑定
  • 审核问题与任务记录

4强制规则
归属隔离
所有 Version、Scene、Shot 查询必须同时带 storyboard_id 与 project_id。
锁定不可变
锁定版本只能读取、导出或派生；任何编辑请求直接拒绝。
稳定引用
镜号可以重排，shot_key 不变；人物规范、问题和资产绑定使用稳定键。
