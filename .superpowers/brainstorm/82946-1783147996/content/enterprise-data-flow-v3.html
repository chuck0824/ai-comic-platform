企业工作台 · 数据模型与关键流程

原则：主数据不复制、领域状态不搬家、聚合读模型可重建、所有写命令回源。

3001：账户与授权事实
Workspace
企业名称、类型、状态、所有者、认证状态
Department
部门树、负责人、启停状态
WorkspaceMember
成员、部门、角色、状态、加入时间
Role / PermissionGrant
权限码 + WORKSPACE / DEPARTMENT / SELF 数据范围
Billing / Usage Limit
共享余额、AI 日/月限额、实际用量
8080：业务事实与企业投影
Purchase Budget Policy
采购月预算、单笔阈值、审批层级；引用 3001 部门 ID
Budget Journal
RESERVE / RELEASE / CONSUME / REVERSE，不保存钱包余额
Domain Requests
交易采购、资产发布、项目导出各自拥有状态机
Approval Inbox Projection
跨域统一分页、筛选和待办；可由事件重建
Dashboard / Audit Projection
只读聚合，保存来源引用和更新时间

流程 1：切换企业工作区

3001 返回可加入 Workspace→ 用户选择→ 刷新 Membership + Grants→ 清理旧空间缓存→ 携带 X-Workspace-Id 重载

流程 2：企业采购预算与审批

提交申请→ 预算原子预占 RESERVE→ 审批→ 批准后等待有付款权限者确认→ 3001 钱包扣款→ 预算 CONSUME

驳回、撤回、过期时 RELEASE；退款成功后 REVERSE。审批通过绝不自动扣款。

流程 3：统一审批收件箱

领域 Outbox 事件→ Approval Projection→ 按权限范围返回 allowed_actions→ 幂等命令路由回原业务域→ 新事件更新收件箱
