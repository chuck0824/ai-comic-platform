收藏记录同时保存 user_id 与 workspace_id：个人偏好不自动共享，但仍受当前 Workspace 上下文隔离。

面向前端的 8080 API

浏览：GET /asset/market/listings、GET /listings/{id}

领取：POST /listings/{id}/claim

资产库：GET /asset/library、GET/PUT /library/{id}

发布：POST /library/{id}/publish 或 /publish-requests

审批：GET /publish-requests、POST /{id}/approve|reject

应用：POST /library/{id}/applications

每个请求的固定校验链

1. 解析登录用户与 8080 当前组织上下文

2. 通过 3001 校验成员状态与操作权限

3. 注入可信 workspace_id

4. Repository 查询强制携带 workspace_id

5. 写审计日志与幂等记录
