新增数据表

  • task_cases：统一摘要、域阶段、健康度、当前责任方、SLA 截止时间；不保存可花费余额。
  • task_case_links：关联生成任务、订单、退款、账本交易、资产、项目和工单。
  • task_events：source + event_id 唯一；保存 aggregate_version、occurred_at、received_at、脱敏 payload。
  • task_attempts：每次执行/重试的开始、结束、错误、费用和 provider request id。
  • task_alerts / reconciliation_cases：告警生命周期、账实差异、自动处置和人工结论。
  • task_commands：命令幂等、请求哈希、操作者、审批、结果和审计链。

主要 API

GET /api/v1/task-center/cases、/cases/{uuid}、/cases/{uuid}/events、/facets。

POST /api/v1/task-center/cases/{uuid}/commands/{action} 统一接收用户命令，后端按域路由。

GET /api/v1/ops/task-center/overview、/exceptions、/reconciliation、/alerts。

GET /api/v1/task-center/stream?cursor=... 提供 SSE 增量；所有列表使用游标或服务端分页。

可靠性与安全规则

  • 事件消费至少一次，依靠唯一事件键和聚合版本实现幂等；乱序事件进入等待/重放，不静默覆盖新状态。
  • 连续消费失败进入死信队列并生成 P1/P2 告警；投影可按 Workspace、Case 或时间段重建。
  • 定时对账比较业务订单、生成结算、3001 账本三方状态；差异先自动查单与补偿，再升级人工工单。
  • 所有查询强制 Workspace 条件；运营跨 Workspace 查询单独授权、记录理由并写审计日志。
  • Prompt、密钥、支付凭证、合同正文和个人信息不进入普通事件 payload；只保存摘要、引用和必要快照。
