复用并增强
  • canvas_projects / nodes / edges：补工作单元、schema 版本和端口契约字段。
  • generation_tasks：继续作为任务事实源，补快照、Attempt、Workspace、幂等和结算引用。
  • 统一任务事件中心：承接状态、重试、取消、费用和异常，不在 Canvas 重建任务中心。
  • 资产服务：继续拥有媒体和版本，Canvas 只保存版本引用。
  • 现有 AiRouter/new-api 负责供应商调用；Canvas 侧只增加能力编译与适配。
必须新增
  • canvas_shot_units：临时镜头与正式 shot revision 的统一容器。
  • director_scenes/drafts/revisions：可变草稿与不可变冻结包彻底分离。
  • generation_request_snapshots：实际模型、适配器版本、输入版本和费用预估。
  • generation_candidates：替代弱语义的 Variant，保留旧 Variant 投影。
  • shot_adoptions：正式采用唯一事实源。
  • delivery_manifests：只做镜头素材清单与 ZIP，不做成片。

API 收敛

  • POST /canvas/nodes/{nodeId}/model-requests/preview：能力校验、推荐模型、输入摘要和费用预览。
  • POST /canvas/nodes/{nodeId}/model-requests：确认后冻结请求快照并创建任务。
  • /canvas/projects/{projectId}/shot-units/{unitId}/director-scene：导演草稿和版本流。
  • POST .../director-revisions/{revisionId}/preview-renders：创建 Blender 任务。
  • POST /shot-units/{unitId}/adoptions：唯一正式采用入口；删除重复的节点级正式采用。
  • POST /canvas/projects/{projectId}/delivery-manifests：固化交付清单和素材包。
  • 所有写接口使用 Idempotency-Key；草稿写入使用 If-Match。
