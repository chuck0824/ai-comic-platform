A · 单体内垂直闭环（推荐）

在现有 Spring Boot 中建立清晰 Agent 领域层，复用认证、项目、画布、生成任务和计费能力。先通过数据库 + 异步执行器 + SSE 做成生产可用闭环。

优势

  • 改造成本最低
  • 事务与权限边界清楚
  • 可逐步拆服务

代价

  • 需控制模块边界
  • 高并发后再独立扩容

B · 独立 Agent 微服务

一次性建设 agent-svc、事件总线、独立存储和工具网关，Agent 与平台业务通过事件和内部 API 协作。

优势

  • 独立扩容
  • 执行隔离好
  • 适合复杂多 Agent

代价

  • 首期复杂度显著增加
  • 分布式事务与联调成本高
增强会话 UI
→
Mock 计划 / 伪状态

C · 前端优先演示版

先补齐会话列表、消息卡片和执行面板，后端仍以 Mock 或一次性同步响应为主。

优势

  • 展示最快
  • 短期改动少

代价

  • 不能形成真实生产闭环
  • 后续大概率重做
