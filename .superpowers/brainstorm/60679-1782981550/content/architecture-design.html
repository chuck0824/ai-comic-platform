设计 1/4：Agent 会话垂直架构

保持单体部署，但用清晰接口隔离会话、规划、审批、执行与业务工具。

一次用户指令的完整链路
Vue Agent 工作台
会话 / 消息 / 计划 / 执行时间线
SSE 接收事件
→
Agent 应用层
SessionService · ContextAssembler
Planner · ApprovalPolicy
ExecutionOrchestrator · EventPublisher
→
AI Router / new-api
结构化计划、对话生成
不直接修改业务数据
↓ 审批通过后
Agent 持久化
sessions · messages · plans
steps · executions · events
←
受控 Tool Registry
READ：查询项目/画布/资产
WRITE：更新节点/创建任务/回写资产
→
现有业务域
项目权限 · 画布 · 生成任务
资产 · 积分 · 审计通知

关键边界

1

模型只做决策

AI 输出结构化 plan/tool call；真正的数据读写只能经过平台 Tool Adapter。

2

审批是服务端规则

查询可直接执行；项目修改、AI 生成、扣费动作必须具有有效 approval。

3

执行异步且可恢复

步骤具备幂等键、状态机、重试策略和检查点，刷新页面不会丢失。

4

事件可观测

SSE 仅传业务事件和摘要，不展示模型隐藏思维链。
