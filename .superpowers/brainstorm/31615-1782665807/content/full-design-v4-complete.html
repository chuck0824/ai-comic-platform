2. 逐集钩子设定与长线钩子

单集钩子卡

上集承接上集留下什么问题，本集如何兑现
开场钩子前 3–5 秒的冲突、危机、信息差或视觉奇观
中段推进冲突升级、爽点/反转、情绪变化
结尾留白未解问题、危险逼近、证据出现或关系突变
下集承诺用户为什么必须继续看
钩子强度0–100 评分、原因、修订建议、用户手动确认

长线钩子层级

  • 全书/全剧大钩子：核心谜题、终极目标、主角身份。
  • 阶段/分卷钩子：每卷目标、阶段反转和阶段兑现。
  • 章节/单集钩子：开场、中段、结尾和下一单元承诺。
  • 伏笔关联：埋设时间、提醒节点、兑现节点、过期预警。
  • 长度决定大钩子密度：20/40/60/80 集或分卷长度自动调整。
每集钩子不只是大纲里的两个文本框。它是可编辑、可评分、可审核、可与上下集和伏笔关联的独立资产。

3. 三智能体编排方案

钩子 Agent 核心常驻

  • 根据模式路由到短剧钩子或 TVC 钩子策略。
  • 检查大钩子、单集钩子、承接钩子、伏笔兑现。
  • TVC 检查注意力、痛点/利益、品牌记忆和 CTA。
  • 不直接覆盖用户内容，输出修订建议或新版本。

编导 Agent 故事成立

  • 检查核心事件、人物动机、冲突升级、关系变化、节奏。
  • 长篇同时检查卷章目标、支线与主线、连续性。
  • 改编阶段检查媒介适配和源作核心保留。
  • TVC 时切换为“创意/转化编导”角色。

导演 Agent 可视化与生产

  • 检查场景数、画面可视化、人物调度、结尾停顿画面。
  • 评估 AI 漫剧生产成本、高难画面和连续性风险。
  • 在分镜阶段负责镜头语言、信息差、声画设计。
  • TVC 检查产品露出、品牌记忆点和分秒节奏。

5. 用户旅程图

1. 明确目标选择短剧、长篇或 TVC，并决定新建还是上传。用户
2. 提供素材输入人物/桥段/简报，或上传已有文稿。用户
3. 结构化AI 提取设定、标签、任务、地点和钩子候选。系统
4. 流程创作用户逐项确认、修订，系统使用修订稿继续生成。人机协作
5. 审核优化三智能体按阶段评审，用户决定是否采纳。人机协作
6. 版本锁定保存新版本、审核并锁定可用稿。用户
7. 派生生产改编、分镜、投流、多平台改版或导入画布。用户+系统

11. 核心验收标准

  • 受众/频向、平台、集数/时长和标签必须进入每次生成的输入快照。
  • 每集具有可编辑的开场、中段、结尾、上集兑现和下集承诺。
  • 每次正文审核都能看到钩子 Agent、编导 Agent和导演 Agent 的独立意见。
  • 上传文稿后可校正分章、提取设定、继续修订与改编。
  • TVC 能独立从简报启动，并使用 TVC 钩子与三智能体审核。
  • 四张图与实际路由、页面和状态枚举保持一致，不再单独维护一份过期流程图。
