剧本与 TVC 创作模块整体重编方案 V3

完整定位：平台提供短剧快速创作、长篇世界观创作、TVC 创作三种独立模式。三种模式均支持 AI/手动输入和用户上传文稿，且都进入可修订、可恢复、可版本化的流程化创作台。

1. 统一入口：三种模式 + 两种内容来源

新建创作

输入人物设定、剧情桥段、产品故事或品牌需求，至少提供一项，AI 补全结构化草案。

导入已有文稿

上传小说、故事稿、剧本、品牌/产品简报或 TVC 草稿，系统解析后由用户确认结构。

短剧快速创作
长篇世界观创作
TVC 创作

2. 用户上传小说或文稿的完整流程

选择模式→上传文件→异步解析→预览原文→调整分章/分集→提取设定→用户确认→进入创作流程

文件与解析

  • P0 保留现有 TXT/DOCX。
  • P1 增加 PDF/Markdown。
  • 记录原文件、解析版本和错误段落。

结构确认

  • 用户可合并、拆分、重排章节/集数。
  • 可指定封面、序章、正文和附录。
  • 确认后生成初始正文版本。

AI 设定提取

  • 人物、关系、地点、世界事实。
  • 主线/支线任务、时间线、伏笔。
  • 所有提取结果先是候选，用户确认后才进入 AI 上下文。
上传不是“解析完直接入库”，而是内容项目的另一种启动方式；用户可继续改文、续写、做长篇编排或改编成短剧/TVC。

3. 三种独立创作流程

短剧快速创作

人物/桥段→梗概/任务→分集大纲→逐集正文→审核锁稿

强调单集钩子、承接、节奏、可视化和 AI 生产成本。

长篇世界观创作

人物/桥段→关系/任务→总纲→分卷→逐章正文→阶段审核

人物和剧情先行，世界、地点、时间线和地图渐进完善。

TVC 创作

需求简报→创意策略→概念/故事→分秒脚本→审核锁稿→分镜/投放

强调注意力、卖点、品牌记忆、信任证明、转化动作和合规。

4. TVC 独立业务逻辑

需求简报

  • 品牌/产品、品类、产品故事。
  • 核心卖点、必须表达、禁止表达。
  • 目标人群、投放平台、使用场景。
  • 5/15/30/60 秒或自定义时长。
  • 目标：认知、种草、转化、招商、形象。

创意策略

  • 输出 3–5 个创意角度和开场钩子。
  • 价值主张、情绪基调、品牌记忆点。
  • 痛点 → 产品介入 → 证明 → CTA 的转化链。
  • 用户确认创意线后再生成脚本。

分秒脚本

  • 时码、画面、动作、镜头意图。
  • 旁白/台词、字幕、音乐/音效。
  • 产品露出、品牌露出、利益证明。
  • 结尾 CTA、平台适配、切片备选。

TVC 审核

品牌 Agent + 转化 Agent + 合规 Agent + 导演/生产 Agent。不复用短剧的“追更审核”。

TVC 去向

保存脚本版本、生成分镜、生成多时长改版、平台适配、投流标题/封面/口播版、导入画布。

6. 共享资产和模式专属资产

短剧/长篇共享

7. 可修订、可恢复、可追溯

选定源版本→组装已确认设定→AI 生成草稿→用户修订→自动保存→新建版本→审核/锁稿
  • 每集、每章、每个 TVC 脚本拥有独立草稿和版本。
  • 退出、刷新、从项目列表重新进入后，恢复到原流程位置。
  • 改编、分镜、投流和画布快照都绑定源版本；源文变更只标记 needs_sync。

现有功能处理新安排

快速/精细模式重编快速变成快速启动；精细 10 步改为模式化阶段轨道。
4 轴标签保留短剧/长篇项目级元数据；TVC 使用品牌/产品标签矩阵。

10. AI 生成与系统保护

Context Assembler

根据所选版本组装用户修订稿和已确认设定，避免后一步继续使用初始 idea。

结构化输出

每个任务拥有 JSON Schema。解析失败明确报错，不使用固定示例冒充成功。

异步与权限

独立 Executor 支持恢复、重试和取消；所有项目和资产 API 校验 owner/member。

11. 分期实施

P0

三模式入口、上传解析闭环、流程化创作台、逐集/逐章/TVC 独立草稿与版本、Context Assembler、结构化输出、项目恢复编辑。

P1

长篇核心设定、总纲/分卷/章节、地点 L0/L1、时间线；TVC 简报、创意策略、分秒脚本和专属审核。

P2

改编/分镜/投流源版本绑定、过期检测、分镜版本化、TVC 多时长/多平台改版、锁定分镜导入画布。

P3

可视化世界/区域地图 L2、人物行程和势力范围；TVC 品牌/产品知识库和合规规则库。

12. 核心验收标准

  • 上传小说后用户可校正分章、修改原文、提取设定并继续创作。
  • TVC 可从产品/品牌简报独立启动，不必先创作小说或短剧。
  • 用户修订梗概、大纲、人物、TVC 策略后，下一步必须使用修订稿。
  • 每集、每章、每个 TVC 版本互相独立，刷新和重新进入不丢失进度。
  • 改编、分镜、投流和画布快照能追溯源版本。
