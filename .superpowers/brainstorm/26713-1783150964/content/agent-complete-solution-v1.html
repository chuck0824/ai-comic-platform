二、首期四个核心 Agent

钩子 Agent

开场抓人秒数、钩子密度、反转强度、章尾悬念、下一集承诺、评分阈值、平台偏好。

接管：重新下钩子、钩子分析、联合审核中的钩子部分。

编剧修订 Agent

修订强度、对白密度、冲突升级、情绪节奏、人物一致性、单集长度、禁改项。

接管：剧本生成、逐集修订、对白与节奏优化。

分镜 Agent

镜头密度、平均时长、A/B/C 档、构图、运镜、切镜节奏、连续性与低成本策略。

接管：A 档拆镜、B 档导演意图、C 档生产字段。

导演 Agent

视觉风格、节奏判断、可拍性、预算约束、审核阈值、问题严重度、建议或修订模式。

接管：导演审核、可拍性判断、剧本/分镜调整建议。
三、Prompt 安全分层
平台锁定层

输入/输出 Schema、审计要求
用户可编辑层
角色方法、判断标准、风格

运行时上下文
项目圣经、当前剧本/分镜
选中范围、临时参数

三层编译为最终 Prompt；执行前校验，执行后冻结快照。

四、配置解析与执行链路
业务入口→ 解析继承范围→ 生成执行快照→ AI Router→ Schema 校验→ 预览 / Diff→ 用户确认→ 新业务版本

配置优先级固定为：单次临时参数 ＞ 项目发布版本 ＞ 用户默认版本 ＞ 系统默认版本。历史任务始终读取自己的执行快照，不随配置更新漂移。

六、后台模块与数据模型
A

AgentTemplate

系统定义的角色能力、锁定规则、参数 Schema、Prompt 基线、输出 Schema、允许工具。

B

AgentVariant / Version

用户派生变体与不可变版本；状态为草稿、已发布、已归档，支持版本 Diff 和回滚。

C

AgentBinding

记录用户默认和项目默认；同一角色、同一作用域只能有一个当前生效版本。

D

TestRun / ExecutionSnapshot

保存试跑输入、结果、评分、成本；正式任务冻结最终 Prompt、参数、模型和来源版本。

新增统一服务：配置解析器、Prompt 编译器、版本发布服务、试跑服务、绑定服务和执行快照服务。业务模块只提交角色类型与上下文，不再硬编码创作 Prompt。

七、权限、错误与治理

规则

  • 个人可创建和发布自己的变体
  • 项目管理员/导演可绑定项目默认
  • 普通成员仅使用或做单次临时调整
  • 发布、回滚、绑定、执行全部记审计

失败处理

  • 配置无效时禁止发布，不静默降级
  • 结构化输出最多自动修复一次
  • 执行中版本变化不影响已冻结快照
  • 权限或项目版本冲突时停止写入
八、迁移与上线顺序
M1 基础
数据表、四个系统模板、配置中心、版本发布
M2 剧本
接入钩子与编剧修订，迁移相关旧 Prompt
M3 分镜
接入分镜与导演，补齐 Diff 与任务选择器
M4 收口
下线旧入口、审计验收、灰度和回滚演练
九、验收标准
  • 四个角色均可复制出多个变体，并完成草稿、试跑、发布和回滚。
  • 同一输入切换 Agent 版本后结果可观察地变化；执行记录能还原所用配置。
  • 项目配置按权限生效，普通成员不能发布或覆盖项目默认。
  • 新版 Agent 不影响历史任务；重跑产生新业务版本，不覆盖旧结果。
  • 代码内四条核心业务链路不再使用硬编码创作 Prompt。
