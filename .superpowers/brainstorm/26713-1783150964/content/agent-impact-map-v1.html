Agent 配置中心：功能改造范围

首期不是单独增加一个设置页，而是让 4 个核心 Agent 真正接管对应业务链路。

新增

Agent 配置中心

角色模板、我的变体、结构化参数、高级 Prompt、草稿、试跑对比、发布、回滚、复制。

新增

项目 Agent 设置

为项目选择钩子、编剧、分镜、导演的默认变体；展示继承来源和当前发布版本。

新增

任务级选择器

在“重新下钩子、修订、生成分镜、导演审核”前选择 Agent，允许临时参数，不直接修改项目默认值。

必须改造的现有业务功能
1

剧本创作与修订

剧本生成、章节/分集修订、对白与节奏优化从“代码内固定 Prompt”改为读取编剧 Agent；结果保存 Agent 版本与执行快照。

2

钩子生成与联合审核

开场钩子、章尾钩子、下一集承诺、钩子评分和联合审核权重改由钩子 Agent 配置；支持按集重跑并生成新版本。

3

专业分镜

A 档拆镜、B 档导演意图、C 档生产提示参数读取分镜 Agent；分镜密度、镜头时长、构图、运镜和场景合并策略可配置。

4

导演审核与调整

导演 Agent 的可拍性、节奏、镜头语言、成本约束和修改建议可配置；建议先生成预览/Diff，确认后形成新剧本或分镜版本。

平台基础能力改造
  • Prompt 管理器：现有 12 槽位入口下线或迁移，避免两套配置源
  • Skill 管理：首期不作为用户主入口；核心角色可复用其执行概念，但不复用松散数据模型
  • Agent 会话：显示当前项目所用 Agent 及版本，创建计划时冻结配置
  • 生成任务：增加 agent_variant_id、agent_version_id、resolved_config_snapshot
  • 权限与审计：项目管理员/导演发布，成员只能单次使用；记录发布和回滚
首期明确不改
  • 不开放用户自定义工具与 API 权限
  • 不改图片、视频、配音模型市场
  • 不让新版 Agent 自动覆盖历史资产
  • 不建设任意节点式多 Agent 工作流
  • 不让用户覆盖安全规则和结构化输出协议
后端核心变化

新增统一配置解析器：业务模块不再自行拼 Prompt，而是传入角色、用户、项目、任务参数；解析器合并继承层级、校验锁定字段并生成不可变执行快照。
