普通模式

只显示业务参数、滑杆、单选项和示例，适合大多数创作者。系统根据参数生成用户可编辑层 Prompt。

高级模式

可编辑角色方法、判断标准、风格指令、变量和 Few-shot 示例；锁定层只读，并提供变量与输出校验。

业务页面中的轻量入口

剧本、钩子、分镜和导演页面不复制完整编辑器，只显示“当前 Agent + 版本 + 切换 + 单次调整”。点击管理后回到配置中心，防止不同模块出现多套配置界面。
