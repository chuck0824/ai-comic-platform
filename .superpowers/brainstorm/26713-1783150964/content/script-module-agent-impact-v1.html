剧本创作模块：Agent 功能改造方案

剧本模块不再只调用固定 Prompt，而是成为“项目上下文 + 用户 Agent + 人工确认 + 内容版本”的协作工作台。

一、改造后的完整创作链路
创作圣经
题材、人物、世界观、禁改项→ 编剧 Agent
大纲 / 分集 / 正文初稿→ 钩子 Agent
开场、反转、章尾、下集承诺→ 导演 Agent
节奏、可视化、可拍性审核→ 用户确认 Diff→ 新剧本版本→ 选择分镜 Agent

这里采用平台固定的协作顺序，不开放用户随意编排工具。用户可以跳过非必需审核，但任何正文修改都先预览、再确认。

二、需要新增的前端功能

1. 项目 Agent 配置

在剧本项目设置中选择默认编剧、钩子和导演 Agent；显示来源为系统默认、用户默认或项目覆盖，并可查看当前发布版本。

2. 创作任务 Agent 选择器

生成大纲、生成正文、重新下钩子、AI 修订、审核前可切换 Agent；支持单次临时参数，并可“另存为新 Agent”。

3. Agent 协作侧栏

展示当前角色、版本、读取的上下文、执行步骤、预计成本、输出摘要；不展示模型隐藏推理。

4. 修订预览与逐段确认

显示原文/建议稿 Diff、修改原因、影响范围；支持逐段接受、全部接受、拒绝和要求 Agent 重做。

5. Agent 结果对比

同一段内容可选择两个 Agent 或版本试跑，比较正文、钩子评分、导演评分、耗时与成本，再采用其中一个。

6. 执行与来源记录

每个内容版本显示由哪个 Agent、哪个版本、哪些临时参数产生，可打开执行快照并从该版本再次运行。

三、现有剧本功能如何改造
A

项目创建与创作首页

保留当前创作模式和源文本选择；新增“使用项目默认 Agent”摘要。高级用户可在创建后进入项目 Agent 设置，不在首屏堆叠完整 Prompt。

B

故事圣经、设定与写作指南

继续作为项目事实源。新增“Agent 可见范围”和锁定字段；Agent 能读取，但不能未经确认修改人物核心设定、世界观规则和已锁字段。

C

大纲与分集生成

由编剧 Agent 生成结构；钩子 Agent 补充每集开场、升级点、章尾和下一集承诺。生成结果携带两个 Agent 的版本快照。

D

正文编辑器

增加选中文本 AI 操作：润色、压缩、扩写、重写对白、增强冲突、增强钩子、按导演意见修订。输出统一走 Patch 预览，不直接覆盖正文。

E

钩子面板

从只展示分析结果升级为可操作工作台：选择钩子 Agent、锁定满意字段、单独重做某一类钩子、查看版本对比、将建议应用到正文。

F

联合审核

钩子和导演评审 Prompt、阈值及重点由各自 Agent 决定；总审核流程和输出 Schema 由平台锁定。审核问题可一键形成修订任务。

G

版本与锁稿

Agent 应用修改后立即创建新内容版本，记录 base_revision、Agent 快照和差异摘要；已锁版本不能原地修改，只能派生新草稿。

H

进入分镜

剧本审核通过后新增“选择分镜 Agent”步骤，将锁定剧本版本、创作圣经和导演意见作为只读输入，生成新的分镜版本。

六、首期不改造的剧本能力

仓库归档、交易市场、版权与授权、源文件上传格式本身保持现状；它们只需要继续引用最终内容版本。图片、视频、配音生成 Prompt 也不并入本期四类 Agent。

七、剧本模块验收标准
  • 用户能为同一剧本项目分别绑定编剧、钩子和导演 Agent。
  • 大纲、正文、钩子、审核四类任务确实读取绑定版本，而不是代码内固定 Prompt。
  • 任何 AI 正文修改都可预览、拒绝和逐段接受，不能静默覆盖。
  • 内容版本可追溯到具体 Agent、版本、临时参数和项目上下文。
  • 发布新版 Agent 不改变已有剧本版本；选择重跑后生成新版本。
