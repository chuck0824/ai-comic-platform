# AI漫剧与视频内容工业化生产工作台商业化落地路线

目标：根据《AI漫剧与视频内容工业化生产工作台 PRD V1.5》，从静态演示页升级为可承载 AI 漫剧、短剧、广告片、短视频生产的商业化平台，对标 Nody / LibTV / NeoWOW 的无限画布、节点编排、批量生成、资产复用、视频合成和 Agent/Skill 自动执行能力。

产品不再定义为“AI 视频生成工具”或“简单自由画布”，而是一套 **AI 视频工业化生产工作台**。核心竞争力不在于单次生成效果，而在于生产流程的工程化、标准化、可追溯、可复用和可规模化。


## P0：生产闭环底座

1. 画布状态持久化
   - 项目、节点、连线、分组、工作流、时间轴、任务状态必须落库。
   - 当前已完成第一版内存 API，可作为前后端合同；下一步迁移到 MySQL 表。

2. 节点引擎
   - 支持基础生产节点：文本、脚本/分镜、图片、视频、音频、角色、场景、道具、合成节点。
   - 节点必须有输入/输出端口、类型校验、上游参数追溯、下游动作菜单。
   - 节点数据模型必须与渲染引擎解耦，后端只保存节点、端口、连线、坐标、尺寸、分组、状态、资产引用和生成参数，不绑定 DOM / SVG / Canvas / WebGL 任一实现。

3. DAG 执行器
   - 对连线图做拓扑排序。
   - 支持并行节点调度、失败重试、断点续跑、任务取消。
   - 生成任务统一进入任务队列，前端只订阅状态，不直接阻塞等待。

4. new-api 模型网关
   - 所有 LLM、文生图、图生视频、TTS、字幕、质量评分统一走 new-api。
   - 模型调用必须记录请求参数、模型版本、成本、耗时、失败原因。

5. 成片导出
   - 时间轴 7 轨：视频、配音、字幕、BGM、音效、特效、图层叠加。
   - 后端合成任务返回进度、预览地址、下载地址、文件元信息。

6. V1.5 P0 功能验收
   - 双击画布新建节点：节点菜单、默认坐标、自动选中、右侧属性联动、刷新后仍存在。
   - 拖入素材自动建节点：文件识别、上传、节点创建、预览、失败处理、自动入库。
   - 脚本节点全屏编辑：表格编辑、字段配置、筛选、批量勾选、导出分镜表。
   - 批量分镜生图：勾选行、批量任务、状态回写、失败重试、自动进入资产库。
   - 批量图生视频：视频节点批量创建、图生视频任务、状态回写。
   - 图片拉出视频节点：从图片右侧端口拖出，弹出下游菜单并创建视频节点。
   - 首尾帧视频：首帧、尾帧、比例校验、过渡描述、任务状态追踪。
   - 全能参考视频：多图、多视频、音频、文本共同参考生成视频。
   - 多副本并行生成：支持 2 / 4 / 8 个候选并行抽卡、人工择优、成本预估。
   - 资产库历史生成：所有生成结果自动沉淀为资产，可检索并拖回画布。
   - 视频合成时间线：多视频、多音轨、字幕、BGM、音效、导出任务。
   - Agent 会话 / Skill 调用：执行计划、算力预估、日志、权限、结果回写画布和资产库。

## P0.5：画布前端引擎技术路线

目标：现在即按可商业化规模设计画布引擎，不把 P0 做成一次性 Demo。技术路线采用 **混合渲染架构**：业务节点优先使用 DOM/SVG + transform 保持可编辑、可调试、可快速迭代；大规模连线、缩略图、小地图、批量预览和高密度场景逐步引入 Canvas/WebGL 渲染；导演台 3D 构图独立使用 WebGL / Three.js。

1. 总体架构
   - 数据层：`canvas_nodes`、`canvas_edges`、`canvas_groups`、`canvas_viewports`、`canvas_selections` 作为唯一事实源，坐标统一使用世界坐标。
   - 状态层：前端维护 pan、zoom、selection、dragging、connecting、contextMenu、history、dirty 标记，支持撤销重做和自动保存。
   - 渲染层：通过 `CanvasRendererAdapter` 抽象 DOM/SVG、Canvas、WebGL 实现，节点和连线数据不因渲染方案变化而迁移。
   - 交互层：统一处理双击新建、拖拽、框选、端口连线、右键菜单、快捷键、缩放平移、素材拖入和小地图导航。
   - 执行层：节点运行状态、任务队列、成本预估、失败重试通过事件流回写到节点，不由渲染层直接调用模型。

2. 推荐首期方案：DOM/SVG + transform
   - 节点使用 Vue 组件渲染，便于承载表单、图片、视频、音频播放器、脚本表格、生成器参数和状态徽标。
   - 连线使用 SVG path 渲染，端口使用 DOM 命中测试，画布容器通过 CSS transform 实现平移缩放。
   - 优点：开发速度快、调试成本低、和当前 Vue 3 / Element Plus 技术栈兼容、复杂节点编辑体验更稳。
   - 风险：节点数量超过 500-1000、连线密集或多媒体预览过多时会出现 DOM 压力，需要虚拟化和 Canvas/WebGL 分层。

3. 图编辑框架评估
   - React Flow：适合 React 技术栈，交互模型值得参考，但当前项目是 Vue 3，不建议作为主实现，避免引入 React 岛和双框架维护成本。
   - Vue Flow：可作为 P0 快速落地候选，适合节点拖拽、端口连线、小地图、控制器、选择态等基础能力。
   - AntV X6：适合更强 DAG/流程图场景，端口、群组、边路由、插件生态较完整，适合作为商业化节点编排引擎候选。
   - 选型原则：P0 以“能快速承载 AI 生产节点”为第一优先级；若重交互和节点编辑更复杂，优先 Vue Flow；若流程图能力、端口规则、边路由和工作流模板更复杂，优先 X6。

4. Canvas / WebGL 渲染策略
   - 原生 Canvas：适合网格背景、选择框、性能敏感的连线层、缩略预览层，不适合直接承载复杂表单节点。
   - Konva：适合 Canvas 2D 场景中的节点、图层、拖拽、变换控制点和图片编辑，适用于图像编辑、Inpaint/Outpaint、分镜组排版等局部能力。
   - Pixi：适合 WebGL 加速的大量贴图、缩略图、视频帧预览、超大画布和高密度资产瀑布流，适合作为 P1/P2 性能升级层。
   - Three.js / WebGL：用于导演台 3D 构图、多视角截图、相机控制和 3D 参考生成，不承担主 2D 节点画布。

5. 商业化演进路径
   - P0：DOM/SVG + transform 或 Vue Flow/X6 先完成节点、连线、缩放、拖拽、右键、自动保存和任务状态回写。
   - P1：引入画布虚拟化，只渲染视口附近节点；连线、小地图、网格背景和大批量缩略图可迁移到 Canvas/Konva/Pixi。
   - P2：对高密度资产、多人协同光标、实时预览和导演台引入 WebGL 加速；建立性能指标：首屏打开、拖拽帧率、缩放帧率、节点上限、连线上限。
   - 长期：保留多渲染器适配层，允许同一项目在“编辑模式”使用 DOM/SVG，在“浏览/播放/大规模预览模式”使用 Canvas/WebGL。

6. 关键验收指标
   - 100 节点 / 300 连线：拖拽和缩放保持 50-60fps，节点编辑无明显延迟。
   - 500 节点 / 1500 连线：启用虚拟化后可流畅浏览，选中、框选、搜索定位可用。
   - 1000+ 节点：可降级到浏览模式或 Canvas/WebGL 预览层，不影响任务执行、资产沉淀和导出。
   - 单个节点必须支持生成中、成功、失败、成本、耗时、模型版本、上游引用和资产入库状态展示。

### P0.5A：前端画布引擎工程拆分

本节用于把技术路线拆成可开发任务。首期不追求一次性实现所有 Canvas/WebGL 能力，而是先保证 DOM/SVG 画布闭环稳定，再为大规模节点和导演台留下适配层。

| 工程包 | 前端任务 | 后端/API依赖 | 测试重点 |
|---|---|---|---|
| 视口与坐标 | 实现 pan/zoom、世界坐标换算、滚轮缩放中心、适配窗口变化 | `canvas_viewports`、节点 `x/y/width/height` | 缩放后端口不漂移，刷新后视口恢复 |
| 节点层 | 实现文本、图片、视频、音频、脚本、导演台节点组件和统一头部/端口/状态徽标 | `GET/POST/PATCH /nodes` 返回 `style_config/input_data/output_data/status` | 空态、结果态、失败态、锁定态显示正确 |
| 连线层 | SVG path、拖线预览、端口命中、兼容类型校验、删除连线 | `/nodes/connect`、`/connections/{id}` | 不兼容端口不能连，删除节点清理孤儿连线 |
| 预设动作 | 文本节点四个尝试动作、自动成组、自动连线、组工具条 | `/nodes/{nodeId}/preset-actions` | 建组不扣费，执行才预估和创建任务 |
| 生成器 | 底部生成器按节点类型切换，参数防抖保存，积分预估展示 | `/credits/estimate`、任务创建接口 | 参数不串用，余额不足禁用提交 |
| 任务状态 | 节点 queued/generating/success/failed/cancelled 状态、日志、重试、取消 | `/generation/tasks/{taskId}`、项目事件流可选 | 成功回写、失败退费、刷新恢复 |
| 分组工作流 | 框选、打组、解组、整组执行、保存工具箱、批量下载 | `/groups`、`/generator-groups` | 解组保留节点和连线，整组按拓扑执行 |
| 性能层 | 视口虚拟化、小地图 Canvas、连线分层、缩略图懒加载 | 节点分页或视口查询可选 | 100/500/1000 节点性能指标达标 |
| WebGL导演台 | Three.js 视口、元素树、相机、FOV、截图回写 | `/director-desk/{nodeId}`、上传资产接口 | 不支持 WebGL 时降级提示，截图生成图片节点 |

**状态机开发要求**

| 状态 | 前端必须展示 | 后端必须返回 |
|---|---|---|
| `unconfigured` | 空态动作、缺少参数提示 | `status`、`style_config.empty_actions` |
| `ready` | 可提交、可预估、结果位置提示 | `ui_flags.can_execute`、生成器参数 |
| `queued` | 排队、取消按钮、任务 ID | `last_task_id`、冻结积分流水 |
| `generating` | 进度、耗时、模型、预计成本 | `progress`、`provider`、`model_id` |
| `success` | 主结果、候选结果、资产入口、重新生成 | `output_data`、`output_asset_ids`、`output_revision` |
| `failed` | 错误原因、重试、复制参数、退费说明 | `last_error_code`、`last_error_message`、`refund` |
| `success + stale` | 上游已变更黄色提示 | `ui_flags.is_stale=true` |

**P0 自动化测试最小集**

1. 创建 100 个节点和 300 条连线，连续缩放、框选、拖拽后刷新，坐标和连线保持一致。
2. 点击文本节点“自己编写内容”，验证富文本工具条出现、无任务、无扣费流水。
3. 点击“文生视频”“图片反推提示词”“文字生音乐”，验证预设组、节点、连线、组工具条和 `run_policy` 正确。
4. 修改视频生成参数，验证积分预估变化；余额不足时提交按钮禁用且不创建任务。
5. Mock 图片/视频/音频任务成功，验证节点结果、资产库、历史记录和积分结算一致。
6. Mock 任务失败，验证节点失败态、错误码、重试入口和退费流水。
7. 修改上游文本，验证下游视频节点进入 `is_stale`，不会自动重新扣费。

## P0.6：LibTV式页面与节点交互逻辑

目标：画布交互必须按 LibTV 的无限画布工作方式设计，让用户围绕“节点 -> 连线 -> 生成 -> 资产 -> 工作流 -> 合成”自然完成生产，而不是跳转到多个割裂页面。所有节点都遵循统一交互骨架，再按节点类型提供专属工具。

1. 页面级交互布局
   - 左上角项目菜单：回到主页、全部项目、创建新项目、删除项目；画布名称支持双击重命名。
   - 左侧栏：添加、工作流、资产、历史记录、教程。添加支持新建文本/图片/视频/音频/脚本/导演台节点，也支持本地图片、视频、音频多选上传并自动生成节点。
   - 右上角个人区：分享/发布、通知、会员/积分、个人中心；积分消耗必须和节点生成任务、成本预估、扣费记录联动。
   - 左下角小地图：展示全局节点分布；拖动小地图高亮框可移动视口；缩放数字常驻展示，滚轮缩放最低 10%，最高 200% 起步，后续可扩展。
   - 底部生成器：选中图片、视频、音频、脚本等生产节点时出现对应生成器；未选中节点时收起，避免遮挡画布。
   - 右侧属性面板：展示所选节点的基础信息、输入输出、生成参数、任务状态、资产引用、成本耗时和上游追溯。

2. 空白画布交互
   - 双击空白处：在鼠标世界坐标打开“新建节点”菜单，选择后在该位置创建节点并自动选中。
   - 右键空白处：打开上下文菜单，支持添加节点、上传资源、粘贴节点、发送工作流模板到此处。
   - 拖入本地文件：识别图片/视频/音频类型，上传后自动创建对应节点；多文件拖入时按网格排列并自动打组。
   - 拖动画布：空格键或中键进入平移；滚轮缩放；框选支持多选节点和连线。
   - 快捷键：Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做，Delete 删除，Ctrl/Cmd+C/V 复制粘贴，Ctrl/Cmd+G 打组，Ctrl/Cmd+Shift+G 解组。

3. 节点通用交互
   - 单击节点：选中节点，显示节点边框、端口、顶部工具条和右侧属性面板。
   - 双击节点内容：进入该节点的主编辑态，例如文本编辑、脚本全屏、图片预览、视频播放、音频波形。
   - 拖拽节点：实时更新世界坐标；松手后节流保存；多选拖拽保持相对位置。
   - 右键节点：复制、粘贴、创建副本、删除、创建资产、创建主体、查看上游、查看任务日志、重新生成、发送到时间线。
   - 复制粘贴：只复制节点内容和参数，不保留连线。
   - 创建副本：复制节点并保留已有连线关系，用于多副本抽卡和同一参考链路下的多版本生成。
   - 删除节点：删除前提示是否同时删除下游连线；支持 Delete 快捷键和撤销恢复。
   - 创建资产：对当前节点资源命名、分类、打标签并保存到资产库；保存后可在左侧资产栏查看、删除、使用并发送回当前画布。
   - 节点状态：待配置、可生成、生成中、成功、失败、已入库、需付费、被锁定；状态以节点头部徽标和右侧面板同时展示。

4. 连线与下游创建
   - 节点右侧端口拖出连线：松手到空白处时弹出下游节点菜单，只显示类型兼容的节点。
   - 图片端口拖出：优先推荐视频节点、图片编辑节点、分镜组、参考图节点。
   - 视频端口拖出：优先推荐视频合成、音视频分离、字幕、配音、解析节点。
   - 音频端口拖出：优先推荐视频合成、配音、音频剪辑、变速节点。
   - 文本端口拖出：优先推荐图片生成、视频提示词、脚本节点、字幕节点。
   - 连接到已有节点：做端口类型校验；不兼容时给出明确原因和可替代节点。
   - 连线语义：文本连接到图片表示作为提示词；图片连接到视频表示首帧/参考图；多图多视频多音频连接到视频表示全能参考；多个视频/音频共同向右拖线表示进入视频合成。
   - 修改上游：标记下游节点为“上游已变更”，允许用户手动重新生成或整组执行。

5. 文本节点
   - 创建方式：双击空白画布、左侧栏添加、粘贴文本自动创建、脚本/Agent 输出自动创建。
   - 编辑方式：支持节点内直接输入、粘贴长文本、右侧面板编辑标题和标签。
   - 生成方式：底部或节点内提供 LLM 文本生成器，可输入自然语言需求或结构化提示词。
   - 下游交互：连接到图片/视频/脚本节点后，文本自动作为提示词、角色设定、旁白或字幕输入参与生成。
   - 必须记录：文本来源、模型版本、生成参数、上游引用、最后编辑人和版本历史。

6. 图片节点
   - 创建方式：本地上传、历史记录发送到画布、资产库发送到画布、图像模型生成、脚本批量生图、视频截图、导演台截图。
   - 生成器：支持文生图、图生图、多图参考融合、图像编辑、风格选择、画幅比、分辨率、生成张数、多副本抽卡。
   - Slash 快捷：在图像生成器输入 `/` 调出快捷命令，至少覆盖九宫格、四宫格、25宫格、角色三视图、光影矫正、画面推演、导演台、视频剪辑、拆分、拼接 2K、全景 720。
   - 顶部工具条：选中图片后自动出现，支持全景 720、多角度、打光、九宫格、高清、扩图、重绘、擦除、抠图、裁剪、宫格切分、标注、旋转、镜像、创建主体、发送到视频。
   - 沉浸模式：宫格切分、焦点编辑、镜头聚焦、标注、Inpaint/Outpaint 进入沉浸态；Esc 退出；确认后结果回填到当前节点或新建节点。
   - 分镜组：框选多张图片后可合并为分镜组，支持比例切换、宫格数量、拼接 2K/4K、序号、清空、转普通组、解组、创建副本。
   - 下游交互：从图片右侧端口拖出创建视频节点；图片自动作为首帧、参考图或风格参考进入视频生成器。

7. 视频节点
   - 创建方式：本地上传、图生视频生成、文本生视频、脚本批量生视频、历史记录/资产发送到画布、视频合成结果回写。
   - 生成器：支持图生视频、首尾帧、全能参考、多模态参考、运镜预设、自定义运镜、时长、比例、生成个数、多副本抽卡和主体调用。
   - 顶部工具条：选中视频后显示高清、解析、剪辑、视频合成、人声/背景音分离、分离音视频、字幕、配音、发送到时间线。
   - 视频解析：对单个视频做分镜拆解，结果以表格展示；全屏后可编辑画面内容、景别、图像提示词、运镜提示词、起止时间、音乐节奏和人声。
   - 视频剪辑：支持片段裁取、播放预览、出入点、键盘微调；I/O 设置入点出点，方向键移动选区，Shift 进入更精细步进。
   - 视频合成：连接两个以上视频节点或视频+音频节点后，向右拖线选择“视频合成”；点击合成节点打开底部时间轴，支持拖动、裁剪、删除、播放预览、半屏剪辑、导出。
   - 下游交互：视频可连接到解析、字幕、配音、合成、音频分离、资产入库和发布流程。

8. 音频节点
   - 创建方式：本地上传、TTS 配音、音乐/音效生成、视频分离音频、历史记录/资产发送到画布。
   - 生成器：支持文字转语音、背景音乐、音效、音色选择、情绪、语速、时长、音量和成本预估。
   - 顶部工具条：选中音频后显示截取、变速、降噪、转字幕、发送到视频合成。
   - 时间线交互：音频可拖入配音轨、BGM 轨、音效轨；支持静音、音量、淡入淡出、裁剪和对齐视频片段。
   - 下游交互：连接到视频合成节点时作为独立音轨；连接到字幕节点时生成字幕时间轴。

9. 脚本节点
   - 创建方式：双击/右键添加、导入剧本、上传角色图+剧情描述、上传参考视频+新需求、Agent 自动创建。
   - 节点内状态：展示脚本摘要、角色/场景数量、镜头数量、批量生成进度和错误数。
   - 全屏视图：支持表格编辑、字段显隐、筛选画面、双击单元格修改、上传角色图/风格参考、切换卡片视图。
   - 批量生图：勾选分镜行，设置风格、模型、比例、分辨率、张数，生成后为每行创建图片节点并回写状态。
   - 批量生视频：分镜图片完成后，可顶部点击批量生成视频；系统按分镜行创建视频节点并回写时长、运镜、状态。
   - 下游交互：脚本节点可整表导出，也可把单行分镜拖出生成图片/视频节点；生成结果必须可追溯到脚本行。

10. 导演台节点
   - 创建方式：双击空白处新建导演台节点，或 Slash /导演台 创建。
   - 打开方式：点击节点内“打开导演台”进入 WebGL 3D 空间。
   - 3D 交互：支持添加人体素模、基础几何、群众阵列、本地模型；V 移动、R 旋转、S 缩放、X 网格吸附，Shift 等比缩放。
   - 摄像机：支持导演视角和机位视角切换，调整 FOV、注视目标、比例截图；截图可发送回画布并自动创建图片节点。
   - 属性面板：左侧管理 3D 元素清单，右侧管理场景、角色、元素、摄像机属性。

11. 工作流与分组
   - 框选多个节点后右键打组，Ctrl/Cmd+G 快捷打组；组可整体拖动、复制、删除和创建副本。
   - 已打组工作流可点击“创建工作流”保存为模板，进入左侧工作流/工具箱。
   - 工作流模板可从左侧发送到当前画布，自动保持内部节点、连线、占位变量和默认参数。
   - 整组执行：按 DAG 顺序执行组内节点；修改上游后可整组重新执行；失败节点可单独重试或跳过。
   - 分镜表节点不参与普通工作流创建；图片分镜组有独立的分镜组逻辑。

12. 历史记录与资产回流
   - 所有图片、视频、音频、字幕、合成结果自动进入历史记录。
   - 历史记录支持查看、删除、批量下载、批量使用，最多一次发送 10 个资源到当前画布。
   - 资产卡片悬浮展示查看、删除、使用；点击使用时在当前视口中心创建节点。
   - 主体库支持角色/商品/人物的一致性资产，图片/视频节点右键可创建主体，视频生成器可调用主体。

## P0.7：节点前端样式、按钮反馈与积分任务说明

目标：每个节点不仅要能操作，还必须让用户在点击前知道“将消耗多少积分、根据什么输入执行什么任务、结果会显示在哪里”。前端样式、交互反馈、积分扣除、任务状态和结果回写必须统一，避免用户把画布当成黑盒。

1. 节点统一视觉结构
   - 节点卡片：默认 320-420px 宽，脚本/分镜/时间线节点可进入宽卡或全屏模式；卡片圆角不超过 8px，选中态使用高亮描边和轻量阴影。
   - 头部区域：左侧显示节点类型图标和可编辑标题，中间显示模型/资产/工作流标签，右侧显示状态徽标、积分预估、更多菜单。
   - 主体区域：文本节点显示编辑器，图片节点显示主图和候选缩略图，视频节点显示播放器，音频节点显示波形，脚本节点显示分镜摘要，导演台节点显示 3D 预览缩略图。
   - 操作区域：主按钮固定放在节点底部或底部生成器中，按钮文案必须带动作和积分，例如“生成图片 · 预计 24 积分”“批量生成视频 · 预计 320 积分”。
   - 端口区域：左侧为输入端口，右侧为输出端口；端口悬停时显示可接受/可输出的数据类型，例如 prompt、image、video、audio、shot、asset。
   - 状态样式：待配置为灰色，已就绪为蓝色，生成中为进度条和转圈，成功为绿色，失败为红色，余额不足为橙色，上游已变更为黄色，已锁定为灰色锁标。
   - LibTV式空态：标题放在卡片外上方，格式为“节点类型 + 序号”；卡片内为深灰底、居中类型图标、“尝试”推荐动作和左右圆形加号端口。
   - LibTV式底部生成器：选中节点后底部弹出深色大面板，主区为 Prompt/剧情输入，底部为模型、比例、清晰度、时长、运镜、张数、翻译/优化、积分预估和提交按钮。

2. LibTV参考节点样式基线
   - 文本节点：外置标题“文本节点 N”，卡片内居中文本图标；尝试动作包括“自己编写内容”“文生视频”“图片反推提示词”“文字生音乐”；底部生成器使用大文本框和 `GVLM 3.1` 类 LLM 模型选择。
   - 图片节点：外置标题“图片节点 N”，卡片内居中图片占位图；尝试动作包括“图生图”“图片高清”；底部生成器包含“风格”“标记”工具块、Prompt 输入、`Lib Image` 类模型、比例/画质/分辨率、摄像机、全景、张数和提交。
   - 视频节点：外置标题“视频节点 N”，卡片内居中播放图标；尝试动作包括“首尾帧生成视频”“首帧生成视频”；底部生成器包含“文生视频 / 全能参考 / 图生视频 / 首尾帧 / 图片参考”模式切换、标记/特效/角色库、比例、清晰度、时长、运镜、候选数和提交。
   - 脚本生成器：外置标题“脚本生成器”，卡片内居中文本图标；尝试动作包括“剧本生成分镜脚本”“角色生成分镜脚本”；底部生成器使用剧情片段输入框和 `GVLM 3.1` 类 LLM 模型选择。
   - 加号端口：左右端口默认展示为圆形加号；左侧用于接收上游素材，右侧用于创建下游节点。点击尝试动作不直接扣费，只切换底部生成器；点击底部提交才进入积分预估和任务创建。

3. 积分与任务通用流程
   - 成本预估：前端根据节点类型、模型、分辨率、时长、生成张数、候选数量、参考素材数量、是否高清/加急等参数调用成本预估接口。
   - 点击付费按钮：弹出确认浮层，展示“本次预计消耗 X 积分、任务类型、输入来源、输出位置”；低成本任务可允许用户勾选“不再二次确认”。
   - 积分冻结：确认后先冻结预计积分并创建 `generation_task`，节点进入生成中；任务成功后按实际消耗结算，多退少补；任务失败按供应商失败原因自动退回或部分结算。
   - 任务执行：所有 AI 任务统一走 AI Router -> new-api，任务 ID 写入节点、任务队列、右侧属性面板和积分流水。
   - 结果回写：结果优先显示在当前节点主体区域；多候选结果显示为候选栏；跨类型结果自动创建下游节点；所有成功结果进入历史记录，可一键创建资产。
   - 失败反馈：失败节点展示失败原因、已扣/已退积分、重试按钮、复制参数按钮和切换模型建议；重试前必须重新展示积分预估。

4. 文本节点样式与交互效果
   - 样式：深色文本卡片，标题外置显示文本图标和“文本节点 N”；空态时主体显示文本占位图标和四个尝试动作；结果态显示文本预览、字数、来源和版本。
   - “自己编写内容”：点击后当前节点进入富文本编辑态，顶部浮出工具条，包含 H1/H2/H3、段落、加粗、斜体、列表、分割线、复制/副本、全屏；节点主体变为可输入文本框，placeholder 为“输入内容...”；不扣积分，不自动成组。
   - “文生视频”：点击后自动创建“预设 - 文生视频”组，组内左侧为文本节点、右侧为视频节点，文本输出连到视频 Prompt 输入；建组不扣积分，点击组工具条“整组执行”或视频节点提交时才预估并扣费。
   - “图片反推提示词”：点击后自动创建“预设 - 图片反推提示词”组，组内左侧为图片节点、右侧为文本节点，图片输出连到文本 Prompt 输入；图片上传/引用不扣 AI 积分，执行反推提示词任务时扣费，结果回写右侧文本节点。
   - “文字生音乐”：点击后自动创建“预设 - 文字生音乐”组，组内左侧为文本节点、右侧为音频节点，文本输出连到音频 Prompt 输入；建组不扣积分，执行音乐生成时扣费，结果显示在音频节点并入资产库。
   - 自动预设组工具条：组被选中时顶部显示组色、布局、整组执行、添加到工具箱、转分镜组、解组、批量下载；其中转分镜组默认置灰，只有组内包含分镜结构时启用。
   - “AI生成/续写”按钮：点击后根据输入字数、目标字数、模型档位预估积分，执行 LLM 文本生成任务；结果显示在当前文本区，并保留上一版本到版本历史。
   - “作为提示词发送”按钮：不扣积分，将文本连接到图片/视频/脚本节点的 prompt 输入；结果显示为目标节点的提示词标签。
   - “生成字幕”按钮：点击后根据文本长度和字幕样式预估积分，执行字幕切分/时间轴任务；结果创建字幕节点或回写到时间线字幕轨。

5. 脚本节点样式与交互效果
   - 样式：脚本生成器采用深色文本卡片，标题外置显示“脚本生成器”；空态显示“剧本生成分镜脚本”“角色生成分镜脚本”；生成成功后升级为脚本/分镜宽卡，展示镜头数、角色数、完成率和分镜摘要。
   - “生成分镜脚本”按钮：点击后根据剧本文字量、集数、目标镜头数、LLM 模型预估积分，执行剧本拆解任务；结果显示在脚本节点全屏表格，并同步镜头数和角色/场景提取结果。
   - “批量生成图片”按钮：点击后根据已勾选分镜行数、模型、分辨率、每行张数预估积分，执行批量生图任务；每行结果回写到分镜表，并在画布中自动创建图片节点。
   - “批量生成视频”按钮：点击后根据已完成图片行数、视频模型、时长、比例、候选数预估积分，执行批量图生视频任务；结果回写到分镜表，并自动创建视频节点。
   - “导出分镜表”按钮：不扣积分，导出当前表格；结果显示为下载文件，同时保留导出记录。

6. 图片节点样式与交互效果
   - 样式：深色媒体卡片，标题外置显示图片图标和“图片节点 N”；空态显示图片占位图标和“图生图/图片高清”；结果态主体显示主图，底部显示候选缩略图、比例、分辨率、来源模型和当前版本。
   - “生成图片”按钮：点击后根据模型、分辨率、张数、参考图数量、风格模板预估积分，执行文生图/图生图任务；结果显示在当前图片节点候选栏，用户选择一张设为主图。
   - “高清”按钮：点击后根据放大倍数、目标分辨率、模式预估积分，执行高清放大任务；结果作为当前节点新版本显示，同时进入历史记录。
   - “扩图/重绘/擦除/抠图”按钮：点击后根据编辑面积、目标尺寸、生成张数和模型预估积分，执行图像编辑任务；结果回写当前节点或按用户选择创建新图片节点。
   - “全景720/多角度/打光/九宫格/角色三视图”按钮：点击后根据快捷命令、输出张数、分辨率预估积分，执行对应图像工具任务；结果显示为候选组，宫格类结果可一键转分镜组。
   - “发送到视频”按钮：不直接扣积分，只从右侧端口创建视频节点并把当前图片作为首帧/参考图；实际扣费发生在视频节点点击“生成视频”时。
   - “创建主体”按钮：点击后根据主体补全张数、描述生成、音色生成等选项预估积分；结果保存到主体库，并在图片节点展示主体标签。

7. 视频节点样式与交互效果
   - 样式：深色视频卡片，标题外置显示播放图标和“视频节点 N”；空态显示播放占位图标和“首尾帧生成视频/首帧生成视频”；结果态主体为播放器，底部显示关键帧、候选版本、时长、比例、分辨率、来源模型和任务状态。
   - “生成视频”按钮：点击后根据视频模型、时长、比例、候选数、首尾帧/全能参考/主体调用预估积分，执行视频生成任务；结果显示在当前视频节点播放器和候选栏。
   - “高清”按钮：点击后根据放大倍数、目标帧率、慢动作强度预估积分，执行视频增强任务；结果作为视频节点新版本显示。
   - “解析”按钮：点击后根据视频时长、解析粒度、是否生成提示词预估积分，执行视频分镜解析任务；结果显示为解析表格，可全屏编辑并发送到脚本/分镜节点。
   - “剪辑”按钮：基础裁剪不扣积分；点击“AI智能剪辑/节奏优化”时根据视频时长和模型预估积分，结果回写当前视频节点的新剪辑版本。
   - “人声分离/分离音视频”按钮：点击后根据视频时长预估积分，执行音视频分离任务；结果自动创建音频节点或静音视频版本。
   - “发送到合成”按钮：不直接扣积分，将视频加入合成节点或底部时间线；最终扣费发生在点击“合成/导出”时。

8. 音频节点样式与交互效果
   - 样式：音频波形卡片，头部显示时长、音色、来源；主体显示波形、播放控制和音量。
   - “生成配音”按钮：点击后根据文本字数、音色、情绪、语速预估积分，执行 TTS 任务；结果显示在音频节点波形，并可自动对齐字幕轨。
   - “生成BGM/音效”按钮：点击后根据时长、风格、循环选项和模型预估积分，执行音乐/音效生成任务；结果显示在当前音频节点并进入历史记录。
   - “截取/变速”按钮：基础截取不扣积分；AI 降噪、智能变速、节奏匹配根据音频时长预估积分；结果作为新版本显示。
   - “转字幕”按钮：点击后根据音频时长、识别语言、是否双语预估积分，执行语音识别任务；结果创建字幕节点并回写到时间线字幕轨。

9. 导演台节点样式与交互效果
   - 样式：3D 节点卡片，主体显示最近一次机位截图，头部显示场景元素数、摄像机数、截图数。
   - “打开导演台”按钮：不扣积分，进入 WebGL 3D 编辑空间；3D 编辑状态保存在导演台节点。
   - “截图发送到画布”按钮：不扣积分，将当前机位截图保存为图片资产并创建图片节点。
   - “普通图转全景/AI布景”按钮：点击后根据目标分辨率、输出视角数、模型预估积分，执行全景或布景生成任务；结果显示在导演台截图列表，并可发送到画布。
   - “多视角批量截图”按钮：不扣积分或仅扣存储/处理积分，结果批量创建图片节点并自动打组。

10. 合成/时间线节点样式与交互效果
   - 样式：宽卡或底部面板，头部显示片段数、总时长、轨道数、导出规格；主体显示预览窗口和多轨时间线。
   - “打开视频合成”按钮：不扣积分，展开底部时间线编辑面板。
   - “预览”按钮：低清本地预览不扣积分；云端预览根据总时长、分辨率、是否含字幕/混音预估积分；结果显示在合成节点预览播放器。
   - “合成”按钮：点击后根据总时长、分辨率、轨道数、转场/字幕/混音复杂度预估积分，执行视频合成任务；结果显示在合成节点，并进入历史记录。
   - “导出”按钮：点击后根据分辨率、码率、是否去水印、商业授权预估积分，执行导出任务；结果显示下载地址、文件大小、有效期，并写入导出记录。

11. 工作流组样式与交互效果
   - 样式：组外框显示工作流名称、节点数、连线数、可执行节点数、预计总积分；组内节点保持各自状态。
   - “整组执行”按钮：点击后汇总所有待执行节点的积分预估，展示执行顺序和并发策略；确认后按 DAG 逐节点冻结/结算积分。
   - “创建工作流”按钮：不扣积分，将组内节点、连线、变量占位、默认参数保存为模板；结果显示在左侧工作流面板。
   - “发送到画布”按钮：不扣积分，将模板实例化到当前视口；变量未填时节点显示待配置状态。
   - “失败重试”按钮：只对失败节点重新预估积分并重试；成功节点不重复扣费，除非用户选择强制重新生成。

## P0.8：每个节点模块的页面布局说明

目标：节点模块不是只有一张卡片，而是一套“画布节点卡片 + 右侧属性面板 + 底部生成器 + 弹窗/全屏编辑器 + 结果回写区”的组合页面。前端实现时必须按模块拆分，保证每个节点在小卡片、选中态、展开态、任务态和结果态都有明确布局。

1. 节点模块通用页面骨架
   - 画布节点卡片：用于快速浏览、拖拽、连线、查看状态和查看最近结果。
   - 节点顶部工具条：仅在节点选中时出现，承载高频工具按钮，例如高清、解析、剪辑、全景、创建资产、发送到视频。
   - 右侧属性面板：用于编辑节点名称、标签、输入输出、生成参数、资产引用、模型配置、任务日志和积分流水。
   - 底部生成器：用于承载复杂生成参数，选中不同节点时切换为图片生成器、视频生成器、音频生成器、脚本批量生成器。
   - 弹窗/全屏编辑器：用于脚本表格、视频解析表、图像重绘、视频剪辑、导演台 3D、时间线合成等重操作。
   - 结果回写区：单结果显示在当前节点主体，多候选显示在候选栏，跨类型结果自动创建下游节点，所有结果同步进入历史记录。
   - LibTV式底部面板：底部生成器默认横向铺满画布底部，不放进节点卡片内部；左侧/上方为模式与工具按钮，中间为大输入区，底部为模型和参数条，右侧为展开按钮、积分提示和提交按钮。

2. 文本节点页面布局
   - 节点卡片：标题外置为文本图标 + “文本节点 N”；空态显示四个尝试动作；编辑态显示富文本输入框和右下角缩放手柄；结果态显示文本预览、字数、来源标签。
   - 富文本工具条：点击“自己编写内容”后显示在节点上方，含清除样式、H1、H2、H3、段落、加粗、斜体、无序列表、有序列表、分割线、复制/副本、全屏。
   - 右侧属性面板：基础信息、文本内容、版本历史、上游来源、下游引用、LLM 参数、积分预估与任务日志。
   - 底部生成器：使用大文本输入区，placeholder 为“写下你想讲的故事、场景或角色设定”；底部参数条显示 `GVLM 3.1` 类模型、翻译/优化、积分预估和提交箭头。
   - 展开态：双击文本主体进入大文本编辑弹窗，支持查找、替换、版本对比和保存。
   - 结果区：AI 生成结果直接覆盖或追加到文本主体，历史版本放入右侧版本列表，下游提示词标签显示在被连接节点中。

3. 脚本节点页面布局
   - 节点卡片：头部显示脚本名、镜头数、角色数、批量进度；主体显示分镜摘要列表；底部显示“生成分镜脚本”“批量生成图片”“批量生成视频”“全屏编辑”。
   - 右侧属性面板：剧本来源、角色图、风格参考、字段配置、批量生成参数、分镜状态统计、任务日志、积分流水。
   - 底部生成器：脚本空态使用剧情片段输入框，placeholder 为“描述剧情片段、故事，为你生成分镜脚本”；生成后按“分镜脚本 / 批量生图 / 批量生视频”三种模式切换，展示模型、比例、分辨率、每行候选数、视频时长和总积分预估。
   - 全屏表格：顶部为操作栏和筛选区，中间为可编辑分镜表，右侧为当前行详情，底部为批量任务栏。
   - 结果区：分镜脚本结果显示在全屏表格；批量图片结果在每行缩略图列展示并在画布生成图片节点；批量视频结果在每行视频列展示并生成视频节点。

4. 图片节点页面布局
   - 节点卡片：头部显示图片图标、标题、比例、分辨率、模型来源；主体为图片预览；底部为候选缩略图、版本切换和主操作按钮。
   - 顶部工具条：全景、多角度、打光、九宫格、高清、扩图、重绘、擦除、抠图、裁剪、宫格切分、标注、旋转、镜像、创建主体、发送到视频。
   - 右侧属性面板：图片元信息、Prompt、参考图、风格模板、模型参数、上游节点、资产状态、版本历史、积分记录。
   - 底部生成器：顶部显示“风格”“标记”工具块；中间为 Prompt 和参考素材；底部参数条显示模型、比例/画质/分辨率、摄像机、全景、翻译、张数、积分预估和提交按钮。
   - 沉浸编辑态：重绘、擦除、裁剪、标注、焦点编辑、镜头聚焦进入全屏或半屏工具；左侧为画布图像，右侧为工具参数，底部为确认/取消。
   - 结果区：生成图片进入当前节点候选栏；高清/编辑结果成为当前节点新版本；宫格/多视角结果可自动创建分镜组或多张图片节点。

5. 视频节点页面布局
   - 节点卡片：头部显示视频图标、标题、时长、比例、分辨率、模型来源；主体为播放器；底部显示候选版本、关键帧和生成状态。
   - 顶部工具条：高清、解析、剪辑、视频合成、人声分离、分离音视频、字幕、配音、发送到时间线。
   - 右侧属性面板：首帧/尾帧、参考素材、运镜参数、主体调用、视频模型、生成时长、任务日志、成本明细。
   - 底部生成器：顶部为“文生视频 / 全能参考 / 图生视频 / 首尾帧 / 图片参考”模式切换；工具块包含标记、特效、角色库；中间为 Prompt 和 `@引用素材`；底部参数条显示模型、比例、清晰度、时长、声音、运镜、候选数、积分预估和提交按钮。
   - 解析/剪辑展开态：解析以全屏表格展示；剪辑以弹窗或半屏显示播放器、时间尺、出入点、选区和快捷键提示。
   - 结果区：生成视频显示在当前播放器和候选栏；解析结果生成表格；音视频分离结果自动创建音频节点；合成结果进入合成节点。

6. 音频节点页面布局
   - 节点卡片：头部显示音频图标、标题、时长、音色/来源；主体为波形和播放控制；底部显示音量、候选版本和主操作按钮。
   - 顶部工具条：截取、变速、降噪、转字幕、发送到视频合成。
   - 右侧属性面板：音频元信息、文本来源、音色、情绪、语速、音量、淡入淡出、任务日志和积分流水。
   - 底部生成器：按“配音 / BGM / 音效 / 转字幕”切换，展示文本输入、音色选择、情绪、时长、语言、总积分预估。
   - 编辑态：截取和变速进入音频编辑弹窗，展示波形、选区、播放头、精确时间输入和确认按钮。
   - 结果区：配音/BGM/音效结果显示为当前音频节点新版本；转字幕结果创建字幕节点或回写时间线字幕轨。

7. 导演台节点页面布局
   - 节点卡片：头部显示导演台图标、场景名、元素数、摄像机数；主体显示最近机位截图；底部显示“打开导演台”“截图发送到画布”“AI布景”。
   - 右侧属性面板：场景配置、元素清单、摄像机列表、截图历史、全景素材、任务日志和积分记录。
   - WebGL 全屏编辑器：左侧为元素库和层级树，中间为 3D 视口，顶部为移动/旋转/缩放/视角工具，右侧为对象属性，底部为摄像机截图列表。
   - 机位视图：切换后中间视口展示当前摄像机画面，右侧调整 FOV、注视目标、比例和截图参数。
   - 结果区：截图结果创建图片节点；AI布景/普通图转全景结果显示在截图历史，并可发送到画布。

8. 合成/时间线节点页面布局
   - 节点卡片：头部显示合成图标、片段数、总时长、导出规格；主体显示最近预览帧；底部显示“打开视频合成”“预览”“合成”“导出”。
   - 右侧属性面板：输入视频/音频列表、轨道配置、字幕样式、转场、导出规格、任务进度、下载记录和积分流水。
   - 底部时间线面板：左侧为轨道列表，中间为多轨时间轴，右侧为预览播放器和导出设置，顶部为播放控制、撤销重做、吸附和缩放。
   - 半屏剪辑模式：上半屏保留画布节点，下半屏显示时间线；拖动视频/音频节点可直接加入轨道。
   - 结果区：预览结果显示在合成节点播放器；合成结果进入历史记录；导出结果显示下载地址、文件大小、有效期和水印状态。

9. 分镜组节点页面布局
   - 节点卡片：组外框显示分镜组标题、图片数量、比例、宫格布局；主体按网格显示图片；底部显示拼接、序号、转普通组、解组。
   - 顶部工具条：比例切换、宫格数量、拼接 2K/4K、序号、清空、转普通组、解组、创建副本。
   - 右侧属性面板：宫格比例、行列数量、排序规则、图片列表、缺失格提示、拼接参数、任务日志。
   - 编辑态：支持拖拽调整宫格顺序、替换单格图片、删除单格、补齐空格。
   - 结果区：拼接结果创建新的图片节点；解组后每张图片恢复为独立图片节点并保留排序。

10. 工作流组页面布局
   - 组卡片：外框显示工作流名称、节点数、连线数、预计总积分、执行状态；组内节点保持原有卡片样式。
   - 组顶部工具条：整组执行、创建工作流、复制副本、解组、变量配置、查看 DAG。
   - 右侧属性面板：工作流说明、变量占位、输入输出、执行顺序、并发策略、节点状态汇总、积分汇总、失败重试策略。
   - 执行确认弹窗：展示待执行节点列表、每个节点预计积分、总积分、执行顺序、失败处理方式和余额校验。
   - 结果区：每个节点结果回写各自节点；整组执行摘要显示在组外框和右侧面板；保存模板后出现在左侧工作流面板。

11. 字幕节点页面布局
   - 节点卡片：头部显示字幕图标、语言、行数、来源；主体显示最近 3-5 行字幕；底部显示“编辑字幕”“发送到时间线”“导出 SRT”。
   - 右侧属性面板：字幕文本、时间码、样式、双语配置、识别来源、任务日志。
   - 全屏编辑器：左侧为字幕行表格，中间为视频预览，右侧为样式面板，底部为时间轴定位。
   - 结果区：字幕生成结果回写字幕节点；发送到时间线后显示在字幕轨；导出结果生成 SRT/VTT 文件。

12. 资产/历史记录发送到画布布局
   - 左侧资产面板：卡片网格展示图片、视频、音频、主体、工作流模板；顶部提供搜索、分类、标签、最近使用。
   - 卡片悬浮操作：查看、使用、删除、创建副本、查看来源；点击“使用”后在当前视口中心创建对应节点。
   - 详情抽屉：展示资产预览、版本、来源节点、生成参数、版权/授权、被引用项目和发送到画布按钮。
   - 结果区：发送后画布自动选中新节点，右侧属性面板展示资产引用关系。

## P1：商业化能力

1. 资产双向联动
   - 画布角色/场景可保存到资产库。
   - 资产库更新可推送到引用该资产的画布项目。
   - 需要版本追溯、锁定保护、冲突处理。

2. 多副本抽卡
   - 同一 Prompt 并行生成 2-8 个候选。
   - QualityAgent 自动评分，人工选择后进入时间轴。
   - 必须有预算上限和成本预估。

3. 工作流模板市场
   - 用户可把已验证节点组保存为模板。
   - 支持官方模板、团队模板、公开市场模板。
   - 模板使用变量占位符，应用时自动填充角色/场景/剧本信息。

4. Agent 操作画布
   - Agent 通过 Tool 调用创建节点、连接节点、执行节点、更新参数、发起质检。
   - 生成结果落盘为可编辑节点，而不是只返回聊天文本。

5. 权限与计费
   - 团队权限：查看、编辑、生成、导出、资产管理。
   - 商业化计费：模型成本、生成次数、导出水印、并发队列、存储空间。

## P2：专业体验

1. 导演台 3D 构图
   - 轻量 3D 场景搭建，多视角截图作为 AI 参考。

2. 专业剪辑体验
   - 片段拖拽、裁剪、转场、字幕样式、音频混音。

3. 实时协作
   - 多人在线编辑、操作日志、版本回滚、评论审阅。
