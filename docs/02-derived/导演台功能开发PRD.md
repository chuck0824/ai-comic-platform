## 2. 产品定位

导演台是画布内的轻量级 3D 构图节点。用户通过“摆积木”的方式搭建故事空间，控制角色站位、物体位置、相机机位和截图比例，快速获得 AI 图像/视频模型可理解的构图参考。

导演台不替代专业 3D 建模软件，也不承担最终渲染生产。它的核心价值是降低创作者对构图、站位、景别、机位、角色相对关系的描述成本，让后续 AI 生图、生视频更稳定。

## 3. 背景与问题

AI 漫剧生产中，用户经常遇到以下问题：

| 问题 | 影响 |
| --- | --- |
| 多角色站位难描述 | 模型容易混淆左右、前后、距离、遮挡关系 |
| 机位和景别不可控 | 同一提示词多次生成时构图差异大，镜头连续性弱 |
| 角色与场景关系不稳定 | 人物朝向、注视对象、空间位置经常漂移 |
| Prompt 文本表达成本高 | 用户需要写大量空间描述，仍难被模型准确理解 |
| 分镜参考图生产链路断裂 | 构图参考、角色参考、场景参考散落在多个节点中 |

导演台通过 3D 低精度占位模型、摄像机和截图，将空间关系转化为图像参考，接入画布生成器链路。

## 4. 目标与非目标

### 4.1 产品目标

1. 用户可以在画布中新建导演台节点，并进入 3D 构图编辑器。
2. 用户可以添加人体素模、基础几何体、群众阵列和本地 3D 模型。
3. 用户可以管理场景元素，包括删除、重命名、打组、解组、隐藏、显示、调色。
4. 用户可以移动、旋转、缩放场景元素，并通过快捷键切换操作模式。
5. 用户可以创建摄像机机位，调整 FOV、画幅比例和注视目标。
6. 用户可以基于导演视角或机位视角截图，并将截图发送到画布成为图片节点。
7. 用户可以上传或选择全景背景，作为空间布景参考。
8. 导演台状态可以自动保存，刷新后恢复 3D 场景、元素、摄像机和截图。

### 4.2 业务目标

| 指标 | 目标 |
| --- | --- |
| 构图参考创建效率 | 用户 3 分钟内完成 2 人对话场景站位并输出截图 |
| 截图使用率 | 导演台截图发送到画布后，被用于生图/生视频任务的比例达到 60% 以上 |
| 重复生成成本 | 多角色分镜的无效抽卡次数降低 30% |
| 用户留存 | 使用导演台的项目，次日继续编辑率高于普通项目 |

### 4.3 非目标

| 非目标 | 说明 |
| --- | --- |
| 不做专业骨骼动画 | MVP 只提供基础姿势预设和有限姿势调整 |
| 不做复杂材质系统 | MVP 只支持颜色、透明度、基础灯光，不做 PBR 材质编辑 |
| 不做高质量最终渲染 | 截图作为 AI 参考图，不作为最终成片画面 |
| 不做多人实时协同编辑 | 可保存共享结果，但不做多人同屏实时操作 |
| 不做完整 3D 模型市场 | MVP 支持内置模型和本地上传，模型市场后置 |

## 7. 端到端业务流程

```text
画布空白处双击
→ 选择导演台节点
→ 节点创建并自动选中
→ 点击打开导演台
→ 进入 3D 编辑器
→ 添加角色 / 几何体 / 群众阵列 / 本地模型
→ 调整元素站位、朝向、大小、颜色、分组
→ 创建或选择摄像机机位
→ 调整 FOV、画幅比例、注视目标
→ 截图
→ 截图进入摄像机截图列表
→ 发送到画布
→ 生成图片节点
→ 作为参考图连接图片/视频生成节点
```

## 9. 功能需求详述

### 9.1 新建导演台节点

| 项 | 要求 |
| --- | --- |
| 触发方式 | 画布空白处双击，选择“导演台”；画布添加菜单；Slash 命令 `/导演台` |
| 创建位置 | 以当前鼠标坐标为节点中心，避免遮挡已有节点 |
| 默认名称 | `导演台 1`，同项目内递增 |
| 默认数据 | 空 3D 场景、默认相机、默认网格、无截图 |
| 创建后行为 | 自动选中节点，右侧画布属性栏展示导演台摘要 |
| 持久化 | 创建后立即写入 `canvas_nodes`，刷新不丢失 |

验收标准：

| AC# | 标准 |
| --- | --- |
| AC01 | 用户双击画布空白区域，可以在节点菜单中看到“导演台” |
| AC02 | 点击后画布出现导演台节点，节点位置与鼠标位置一致 |
| AC03 | 刷新页面后，导演台节点仍在原位置 |
| AC04 | WebGL 不可用时，节点可创建，但打开编辑器时展示降级提示 |

### 9.2 打开与关闭编辑器

| 项 | 要求 |
| --- | --- |
| 打开入口 | 节点主体按钮“打开导演台”；节点更多菜单“编辑 3D 场景” |
| 打开形式 | 全屏弹层或独立编辑路由，默认保留画布上下文 |
| 加载内容 | 读取导演台状态，包括对象、分组、摄像机、截图、全景资源 |
| 关闭方式 | 顶部返回画布、Esc、右上角关闭 |
| 未保存变更 | 自动保存中不可关闭；保存失败时提示“保存失败，是否放弃本次修改” |
| 返回画布 | 回到原画布视口，并选中当前导演台节点 |

### 9.11 AI 识图导入场景

AI 识图导入用于将本地图片或历史图片识别为导演台参考场景。它不是普通图片上传：系统需要识别图片中的空间结构、主体位置和环境信息，并转换为导演台可用的全景背景或站位参考。

入口：

| 入口 | 说明 |
| --- | --- |
| 底部图片上箭头按钮 | Tooltip 为“AI识图导入”，点击打开弹窗 |
| 720 菜单中的 AI生成 | 可复用同一弹窗或跳转到全景生成流程 |

弹窗结构：

| 区域 | 控件 | 要求 |
| --- | --- | --- |
| 标题栏 | `AI 识图导入`、关闭按钮 | 点击关闭时不影响已提交的生成任务 |
| Tab | 本地上传、历史记录 | 默认选中本地上传 |
| 上传区 | 点击上传图片或拖拽图片至此上传 | 上传后画布将新建一个图片节点并自动替换当前图源 |
| 覆盖方式 | 插入当前导演台 | 作为站位参考层插入，不覆盖当前全景、角色和机位 |
| 覆盖方式 | 覆盖当前导演台 | 覆盖当前全景、角色和机位；高风险操作，MVP 默认置灰或二次确认 |
| 底部提示 | 退出不会中断生成过程，全景图生成成功后会自动加载到背景 | 任务异步执行 |
| 主按钮 | 识图导入场景 | 上传或选择图片后可点击 |

处理规则：

| 场景 | 规则 |
| --- | --- |
| 本地上传 | 上传成功后生成图片资产，并作为识图任务输入 |
| 历史记录 | 选择已有图片资产作为识图任务输入 |
| 插入当前导演台 | 保留当前对象、机位和全景，仅新增参考层或背景候选 |
| 覆盖当前导演台 | 清空或替换全景、角色、机位前必须二次确认 |
| 任务中关闭弹窗 | 不取消任务，任务完成后通过通知和导演台背景自动回写 |
| 任务失败 | 保留原导演台状态，提示重新导入 |

输出结果：

| 输出 | 说明 |
| --- | --- |
| 全景背景 | 识别或生成后的全景图自动加载到 3D 场景背景 |
| 站位参考层 | P1 支持将原图作为半透明参考平面插入 |
| 结构化信息 | 记录识别出的主体、地平线、透视方向和场景描述 |
| 资产记录 | 生成结果进入项目资产库和生成历史 |

### 9.12 保存、撤销与版本

保存策略：

| 类型 | 触发 | 要求 |
| --- | --- | --- |
| 自动保存 | 停止编辑 1 秒后 | 增量保存导演台状态 |
| 手动保存 | 用户点击保存 | 立即保存并提示成功/失败 |
| 关闭前保存 | 返回画布时 | 若有变更，先保存再退出 |
| 节点保存 | 发送截图到画布时 | 同步更新节点预览和输出数据 |

撤销范围：

| 操作 | 是否支持撤销 |
| --- | --- |
| 添加/删除对象 | 支持 |
| 移动/旋转/缩放 | 支持 |
| 调整颜色/名称/显示/锁定 | 支持 |
| 创建/删除摄像机 | 支持 |
| 创建截图 | 支持撤销截图记录，不删除已发送图片节点 |
| 发送到画布 | 不纳入导演台撤销，由画布撤销管理 |

版本策略：

| 阶段 | 方案 |
| --- | --- |
| MVP | 保存当前态，不做历史版本 UI |
| P1 | 每次手动保存生成快照，支持恢复 |
| P2 | 支持版本对比和团队模板 |

## 12. 前端实现要求

### 12.1 技术建议

| --- | --- |

| Safari | 支持 WebGL2 时可用；不支持时降级提示 |

| 指标 | MVP 标准 |

| 保存延迟 | 2 秒内完成一次普通状态保存 |
| 截图耗时 | 2K 单张截图 5 秒内完成 |

## 14. 算法与生成链路

导演台本身不直接调用生图模型，但其截图可作为参考图参与下游生成。

### 14.1 参考图接入规则

| 下游节点 | 接入方式 | 要求 |
| --- | --- | --- |
| 图片节点 | 作为构图参考图 | 记录来源 `source=director_desk_screenshot` |
| 视频节点 | 作为首帧/构图参考 | 保留截图画幅和机位信息 |
| 脚本节点 | 作为 shot 参考图 | 可绑定到指定 shot |

### 14.2 Prompt 辅助信息

发送到下游生成时，可附带结构化辅助信息：

```json
{
  "composition_ref": {
    "source": "director_desk",
    "camera": {
      "fov": 50,
      "aspect_ratio": "16:9",
      "look_at": "角色A"
    },
    "objects": [
      { "name": "角色A", "type": "character", "color": "blue", "relative_position": "left" },
      { "name": "角色B", "type": "character", "color": "red", "relative_position": "right" }
    ]
  }
}
```

该信息由生成器用于补充 Prompt，不要求用户手动编辑。

### 14.3 AI 识图导入算法要求

| 输入 | 输出 | 要求 |
| --- | --- | --- |
| 本地上传图片 | 图片资产 | 原图进入资产库，保留来源和尺寸 |
| 普通场景图 | 全景背景候选 | 尽量生成可用于 3D 视口背景的 2:1 全景图 |
| 普通场景图 | 结构化场景信息 | 输出场景描述、地平线位置、透视方向、主要空间区域 |
| 普通场景图 | 站位参考层 | P1 支持生成半透明参考平面或背景层 |

算法边界：

| 项 | 要求 |
| --- | --- |
| 插入模式 | 不改变当前角色、机位和几何体，只新增背景或参考信息 |
| 覆盖模式 | 允许重建场景背景和参考层，但不直接删除用户资产 |
| 失败回滚 | 识别或生成失败不影响现有导演台状态 |
| 任务通知 | 任务完成后自动通知前端刷新导演台状态 |

## 17. 异常与边界场景

| 场景 | 处理 |
| --- | --- |
| 浏览器 WebGL 不可用 | 展示图形加速提示，不进入编辑器 |
| 自动保存失败 | 顶部保存状态显示失败，提供重试 |
| 断网编辑 | 保留本地临时状态，恢复网络后提示保存 |
| 模型加载失败 | 元素树保留失败态，可删除或重试 |
| 截图失败 | 截图列表不新增记录，提示重试 |
| 发送到画布失败 | 截图保留，提示重新发送 |
| 删除来源导演台 | 已发送图片节点保留，来源信息标记为已删除 |
| 删除截图 | 已发送图片节点不受影响 |
| 对象过多 | 提示性能风险，禁止继续添加超过上限 |
| 多端同时编辑 | 后保存者触发版本冲突提示 |

## 18. 验收标准

### 18.1 主流程验收

| 用例 | 操作 | 预期结果 |
| --- | --- | --- |

| 添加群众阵列 | 在群众弹层设置 3 行、3 列、间距 1.2 后点击添加 | 场景生成 9 个群众对象并自动打组 |
| 调整站位 | 使用 V/R/S 调整角色位置、旋转、缩放 | 模型变化实时生效，保存后可恢复 |
| 改色 | 选中模型修改颜色 | 视口和截图中的颜色同步变化 |
| 打组 | 多选两个角色 Ctrl+G | 元素树出现分组，子元素归入分组 |
| 模式菜单 | 点击底部箭头按钮 | 展示移动 V、旋转 R、缩放 S，点击后切换对应 gizmo |
| 创建机位 | 调整导演视角后点击截图 | 新建机位并生成截图 |
| 选择机位预设 | 点击底部摄像机按钮并选择“正面中景” | 自动创建/切换正面中景机位 |
| 机位视角 | 切换到机位视角 | 视口显示摄像机取景内容 |
| 调整 FOV | 修改 FOV 滑块 | 画面透视变化，截图使用新 FOV |
| 选择截图比例 | 点击底部比例按钮并选择 9:16 | 视口显示 9:16 取景框，截图按 9:16 输出 |
| 注视目标 | 摄像机注视角色 A，移动角色 A | 开启自动跟随时摄像机焦点跟随 |
| 全景菜单 | 点击底部 720 按钮 | 展示本地上传、历史记录、AI生成 |
| AI 识图导入 | 点击底部图片上箭头按钮，上传图片并选择插入当前导演台 | 任务创建成功，完成后全景背景或参考层回写导演台 |
| 全屏切换 | 点击底部全屏按钮 | 编辑器进入全屏，再次点击退出全屏 |
| 发送画布 | 选中截图发送到画布 | 创建图片节点并与导演台节点连线 |
| 刷新恢复 | 刷新浏览器后重新打开导演台 | 对象、机位、截图全部恢复 |

## 21. 风险与依赖

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| WebGL 兼容差异 | 部分用户无法打开 | 启动前检测，给出图形加速提示 |
| 上传模型过重 | 卡顿、崩溃 | 限制大小和面数，加载前提示 |
| 截图跨域污染 canvas | 无法导出截图 | 模型、纹理、全景资源统一走可信 CDN 并设置 CORS |
| 状态 JSON 过大 | 保存慢、接口失败 | 对截图和资源只存引用，限制对象上限 |
| 与画布快捷键冲突 | 操作误触 | 编辑器聚焦时接管快捷键，退出后释放 |
| 下游模型不严格遵循构图 | 参考图价值下降 | 截图加结构化构图信息，生成器提示词自动补充 |

### 23.5 当前边界与后续补齐
