## 1. 文档目的

本文整理“钩子 Agent”在剧本创作与 TVC 创作中的产品逻辑、分类体系、用户流程和开发落地建议，便于产品经理、设计、前后端开发和 AI Prompt/Agent 开发统一理解。

核心结论：

- 钩子不是单纯的开头文案，也不是只在每集结尾放一个悬念。
- 钩子应作为内容结构控制器，参与选题、分集大纲、单集剧本、分镜和投流素材生成。

> **[superpowers 更新]（2026-07-02）**：
> - **创作圣经集成**：钩子策略模板纳入创作圣经的写作指南 L1 层；连续性快照包含钩子履行状态。详见 `docs/superpowers/specs/2026-07-02-script-creation-creative-bible-design.md`
> - **解耦架构**：钩子前移至小说创作阶段（而非脚本/分镜阶段）。参见 `小说正文与分镜脚本解耦改造方案.md`
- 钩子 Agent 应先区分大类：剧本 / TVC。
- 大类之下还需要结合小分类、受众、题材、情节、情绪/基调、时空背景、内容长度等维度，生成不同的钩子策略。
- 剧本类重点是追更粘性，TVC 类重点是注意力、记忆和转化。
- 剧本每集审核应内嵌钩子 Agent、编导 Agent 和导演 Agent：钩子负责追更，编导负责故事成立，导演负责画面和 AI 生产落地。

## 2. 背景与问题

当前剧本创作流程中已经存在“开场钩子”“结尾悬念”等概念，但如果只把它们做成两个文本字段，会有几个问题：

1. 无法根据故事总长度安排阶段性大钩子。
2. 无法保证每集内部的观看节奏。
3. 无法保证上一集和下一集之间有承接关系。
4. 无法区分男频、女频、双频、不同题材和不同情绪基调的钩子差异。
5. 无法支持 TVC 这种非追更型内容，因为 TVC 的钩子目标是转化、记忆和品牌/产品认知。

因此，需要将“钩子”升级成独立的钩子 Agent 能力。

## 3. 核心定义

### 3.1 钩子

钩子是让用户继续观看、继续追更、产生记忆或采取行动的内容结构点。

在剧本中，钩子主要服务于：

- 当前集看完。
- 下一集点击。
- 长期追更。
- 角色、关系、秘密、冲突和爽点的持续推进。

在 TVC 中，钩子主要服务于：

- 前几秒抓住注意力。
- 快速建立痛点或利益点。
- 让用户记住品牌/产品。
- 促成咨询、购买、转发或品牌认知。

### 3.2 大钩子

大钩子是根据故事总长度设置的长期追更悬念或阶段目标。

示例：

- 女主真实身份什么时候暴露？
- 男主什么时候发现当年真相？
- 反派背后真正操控者是谁？
- 主角什么时候第一次完成打脸？
- 两个人关系什么时候破冰？

不同故事长度的大钩子密度不同：

| 故事长度 | 大钩子建议 |
| --- | --- |
| 20 集 | 高密度推进，3-5 集一次明显反转或阶段高潮 |
| 40 集 | 拆成 4-5 个阶段，每 8-10 集一个大钩子 |
| 80 集 | 主线大钩子 + 多条支线钩子，避免中段疲劳 |

### 3.3 单集钩子

单集钩子是一集内部的节奏点。它不是一个点，而是一条小型强度曲线。

推荐默认结构：

```text
开场钩子 → 人物/信息交代 → 冲突出现 → 冲突升级 → 爽点/反转 → 结尾留白
```

### 3.4 承接钩子

承接钩子负责上一集和下一集之间的连续性，是提高用户粘性的关键。

推荐结构：

```text
上一集问题 → 本集部分兑现 → 本集制造新问题 → 下一集承诺
```

示例：

```text
第 3 集结尾：男主看到女主手腕旧疤。
第 4 集开头：男主追问旧疤来历。
第 4 集中段：女主撒谎掩盖。
第 4 集结尾：男主找到旧案照片，照片里的人像女主。
```

## 4. 钩子 Agent 总体架构

建议不要把系统做成很多完全割裂的 Agent，而是做成：

```text
钩子 Agent Router
├─ 剧本类 Hook Agent
│  ├─ AI 漫剧钩子策略
│  ├─ 短剧钩子策略
│  ├─ 网剧钩子策略
│  ├─ 连载漫画/漫剧策略
│  └─ 长篇故事/系列剧策略
│
└─ TVC 类 Hook Agent
   ├─ 品牌 TVC 策略
   ├─ 产品卖点 TVC 策略
   ├─ 电商转化 TVC 策略
   ├─ 招商/发布 TVC 策略
   └─ 公益/形象 TVC 策略
```

底层实现上可以理解为：

```text
Hook Agent Router
= 大类 Agent
+ 内容小类模板
+ 受众频向权重
+ 题材钩子库
+ 情节钩子库
+ 情绪基调规则
+ 时长节奏模板
+ 平台投放偏好
```

产品上可以叫“不同钩子 Agent”，开发上建议落成“Agent Router + 策略模板库 + 标签权重规则”。

## 5. 大分类与小分类

### 5.1 大分类

| 大类 | 核心目标 | 核心钩子逻辑 |
| --- | --- | --- |
| 剧本 | 追更粘性 | 大钩子、单集钩子、承接钩子、反转、爽点、留白 |
| TVC | 认知/转化 | 注意力、痛点、产品利益、品牌记忆、行动号召 |

### 5.2 剧本小分类

| 小分类 | 钩子重点 |
| --- | --- |
| AI 漫剧 | 强画面钩子、强冲突、强反转、可转分镜和视频 Prompt |
| 短剧 | 快节奏冲突、爽点兑现、集末追更 |
| 网剧 | 人物关系、阶段悬念、长期情绪积累 |
| 连载漫画/漫剧 | 视觉悬念、分格留白、章节结尾点击 |
| 长篇故事/系列剧 | 主线钩子、支线钩子、阶段性高潮 |

说明：这里的 AI 漫剧和传统短剧、网剧在戏剧逻辑上是一致的，都需要冲突、反转、爽点和追更承接；区别在于 AI 漫剧还需要将钩子进一步落到画面、分镜、角色资产和视频生成指令。

### 5.3 TVC 小分类

| 小分类 | 钩子重点 |
| --- | --- |
| 品牌 TVC | 品牌记忆、情绪价值、价值主张 |
| 产品 TVC | 痛点、卖点、使用场景、效果证明 |
| 电商转化 TVC | 价格/利益刺激、限时感、点击/购买动作 |
| 招商/发布 TVC | 信任背书、市场机会、合作行动 |
| 公益/形象 TVC | 情绪共鸣、社会议题、价值表达 |

## 6. 标签矩阵

大类和小类只能决定大方向，真正生成钩子策略时，还要叠加标签矩阵。

### 6.1 剧本标签矩阵

| 维度 | 示例 | 对钩子的影响 |
| --- | --- | --- |
| 受众频向 | 男频、女频、双频 | 决定爽点、关系、目标、情绪权重 |
| 题材 | 都市、言情、玄幻、悬疑、家庭、职场 | 决定冲突类型和大钩子类型 |
| 情节 | 重生、复仇、打脸、先婚后爱、身份反转、破案 | 决定钩子的推进方式 |
| 情绪/基调 | 爽感、甜宠、虐恋、悬疑、热血、治愈 | 决定钩子强度和表达方式 |
| 时空背景 | 现代、古代、民国、未来、豪门、校园、职场 | 决定场景、身份和视觉钩子 |
| 长度 | 总集数、单集时长 | 决定大钩子密度和单集节奏 |
| 平台 | 抖音、快手、视频号、TikTok 等 | 决定前几秒强度和投流表达 |

### 6.2 男频、女频、双频差异

男频常见钩子逻辑：

```text
压制 → 觉醒 → 反击 → 打脸 → 升级 → 更大敌人出现
```

常见钩子：

- 主角被羞辱，但隐藏身份即将暴露。
- 反派以为赢了，主角亮出底牌。
- 本集打脸兑现，结尾引出更高层敌人。
- 修为、财富、权力、系统能力升级。

女频常见钩子逻辑：

```text
关系误会 → 情感拉扯 → 身份秘密 → 反差宠爱 → 虐点 → 情绪反转
```

常见钩子：

- 女主被误会，男主开始动摇。
- 替身身份即将曝光。
- 男主冷漠外表下第一次破例。
- 女主刚要离开，男主发现真相。

双频常见钩子逻辑：

```text
强冲突 + 清晰目标 + 情绪共鸣 + 信息差 + 普适爽点
```

适合悬疑、末世、家庭伦理、喜剧、职场逆袭等题材。

### 6.3 TVC 标签矩阵

| 维度 | 示例 | 对钩子的影响 |
| --- | --- | --- |
| 目标人群 | 年轻女性、宝妈、企业主、中老年、高净值、下沉市场 | 决定痛点和表达语气 |
| 行业品类 | 美妆、食品、教育、房产、汽车、医疗、SaaS | 决定场景和信任背书方式 |
| 核心诉求 | 种草、转化、信任、记忆、招商、品牌认知 | 决定结尾行动 |
| 情绪基调 | 高级、温暖、焦虑解决、爽感、专业、科技感 | 决定画面和文案风格 |
| 使用场景 | 家庭、办公、户外、直播间、门店、发布会 | 决定视觉钩子 |
| 时长 | 5 秒、15 秒、30 秒、60 秒、自定义 | 决定节奏模板 |

## 7. 根据长度生成钩子策略

### 7.1 剧本长度

剧本类需要同时考虑总长度和单集长度：

```text
总集数 → 决定大钩子密度
单集时长 → 决定单集内部节奏段数量
```

单集长度建议：

| 单集时长 | 推荐结构 |
| --- | --- |
| 15-30 秒 | 强钩子 → 冲突 → 反转/行动 |
| 60-90 秒 | S1-S6 六段式节奏 |
| 2-5 分钟 | 8-12 个 beat，中间需要多次小钩子 |

### 7.2 TVC 长度

TVC 的长度由用户选择，可以提供默认时长：

| TVC 时长 | 推荐结构 |
| --- | --- |
| 5 秒 | 强视觉/强痛点 + 品牌/产品露出 |
| 15 秒 | 钩子 + 产品利益点 + 记忆点 |
| 30 秒 | 问题场景 + 解决方案 + 证明 + 行动号召 |
| 60 秒 | 微剧情/情绪铺垫 + 产品价值 + 品牌记忆 + 转化 |
| 自定义 | 根据秒数自动拆分节奏段 |

## 8. 单集钩子强度曲线

用户提出的钩子强度曲线可以作为产品 UI 和 Agent 规则基础。

示例：

```text
钩子强度
  ★★★★★ |          ██
          |         ████
  ★★★★☆ | ██     ██████    ██
          | ████   ████████  ████
  ★★★☆☆ | ██████ ██████████ ██████ ██
          | ██████████████████████████████
  ★★☆☆☆ | ██████████████████████████████
          |________________________________
          S1    S2    S3    S4    S5    S6
          强钩   人物   冲突   冲突   技艺   高潮→留白
```

S1-S6 可以理解为一集内部的节奏段，而不是固定集数：

| 段落 | 默认名称 | 功能 |
| --- | --- | --- |
| S1 | 强钩 | 前 3-5 秒抓住注意力 |
| S2 | 人物 | 快速建立人物、关系或信息差 |
| S3 | 冲突 | 冲突出现 |
| S4 | 冲突升级 | 误会、危险、反转或压迫升级 |
| S5 | 技艺/爽点 | 释放爽点、情绪、技能或关键动作 |
| S6 | 高潮留白 | 高潮后停住，承接下一集 |

默认策略可以由系统生成，用户也可以手动调整每个段落的强度、功能和文案。

## 9. 产品流程建议

### 9.1 用户入口

第一步：选择内容大类。

```text
- 剧本
- TVC
```

第二步：选择小分类。

```text
剧本：AI 漫剧 / 短剧 / 网剧 / 连载故事 / 长篇故事 / 其他
TVC：品牌片 / 产品片 / 电商广告 / 招商片 / 公益片 / 其他
```

第三步：填写标签矩阵。

剧本：

```text
受众频向：男频 / 女频 / 双频
题材：都市 / 言情 / 玄幻 / 悬疑 / 家庭 / 职场 / 自定义
情节：重生 / 复仇 / 打脸 / 先婚后爱 / 身份反转 / 自定义
情绪/基调：爽感 / 甜宠 / 虐恋 / 悬疑 / 热血 / 治愈 / 自定义
时空背景：现代 / 古代 / 民国 / 未来 / 豪门 / 校园 / 职场 / 自定义
长度：总集数 + 单集时长
```

TVC：

```text
目标人群
行业品类
核心诉求
情绪基调
使用场景
TVC 时长
```

第四步：选择或生成钩子策略。

```text
- 默认策略
- 强投流策略
- 高反转策略
- 情绪拉扯策略
- 爽点打脸策略
- 品牌记忆策略
- 产品转化策略
- 自定义策略
```

第五步：进入钩子曲线编辑器。

用户可以：

- 查看系统生成的钩子强度曲线。
- 拖拽调整每段强度。
- 修改每段功能，如强钩、人物、冲突、爽点、留白。
- 修改每集开头、结尾和承接钩子。
- 保存为个人模板。

### 9.2 剧本类生成流程

```text
输入创意与标签
→ 钩子 Agent 生成全剧钩子策略
→ 生成大钩子曲线
→ 生成分集大纲，每集带开场钩子、内部节奏、结尾悬念、下一集承诺
→ 用户编辑钩子曲线
→ 生成单集剧本
→ 钩子 Agent 质检并重写弱钩子
→ 生成分镜与投流素材
```

### 9.3 TVC 类生成流程

```text
输入产品/品牌信息与标签
→ 选择 TVC 时长
→ 钩子 Agent 生成时长节奏模板
→ 生成开头注意力钩子、痛点、利益点、证明、行动号召
→ 用户编辑节奏和文案
→ 生成 TVC 脚本
→ 生成分镜、画面 Prompt 和投流素材
```

### 9.4 在现有剧本创作功能中的位置

钩子 Agent 不建议做成独立主菜单，应嵌入现有“剧本创作”主流程，作为创作引擎的一部分。

推荐放置位置：

| 现有步骤 | 功能放置 | 用户感知 |
| --- | --- | --- |
| Step 1：输入创意与设置参数 | 增加内容大类、受众频向、内容小类、长度、钩子风格配置 | 让用户先确定钩子策略 |
| Step 4：分集大纲 | 升级为钩子 Agent 核心编辑区 | 用户编辑全剧大钩子、每集钩子、S1-S6 曲线和承接关系 |
| Step 5：剧本编辑器 | 增加每集审核面板 | 钩子 Agent、编导 Agent、导演 Agent 对单集剧本进行审核 |
| Step 6：分镜脚本 | 接收导演 Agent 的生产建议 | 分镜生成更贴近画面表达和 AI 生产要求 |
| Step 7：投流素材 | 复用强钩子和高转化片段 | 生成标题、封面、3 秒钩子和切片脚本 |

一句话：

```text
钩子 Agent 的入口在创作参数页，核心编辑在分集大纲页，审核和重写在剧本编辑页，导演建议进入分镜页。
```

### 9.5 平台用户操作路径

剧本用户路径：

```text
进入剧本创作
→ 选择 AI 写作
→ 选择内容大类：剧本
→ 选择 AI 漫剧 / 短剧 / 网剧
→ 设置男频 / 女频 / 双频
→ 设置题材、情节、情绪/基调、时空背景
→ 设置总集数和单集时长
→ 选择钩子风格或使用默认策略
→ 生成钩子策略
→ 生成分集大纲
→ 在分集大纲页调整大钩子、每集钩子和 S1-S6 曲线
→ 锁定关键钩子
→ 生成单集剧本
→ 每集审核：钩子 Agent + 编导 Agent + 导演 Agent
→ 用户选择一键优化、局部修改或通过
→ 生成分镜
→ 生成投流素材
→ 保存入库或送入画布工作台
```

TVC 用户路径：

```text
进入剧本创作
→ 选择内容大类：TVC
→ 选择品牌 TVC / 产品 TVC / 电商 TVC / 招商 TVC 等
→ 填写目标人群、行业品类、核心诉求、情绪基调和使用场景
→ 选择 TVC 时长：5 秒 / 15 秒 / 30 秒 / 60 秒 / 自定义
→ 钩子 Agent 生成分秒节奏
→ 用户调整开头钩子、卖点、记忆点和行动号召
→ 生成 TVC 脚本
→ TVC 审核：注意力、卖点清晰度、品牌记忆和转化动作
→ 生成分镜、画面 Prompt 和投流素材
```

## 10. Agent 工作职责

钩子 Agent 应介入生成前、生成中、生成后三个阶段。剧本类每集审核还应加入编导 Agent 和导演 Agent，形成多 Agent 把关闭环。

### 10.1 生成前：策略规划

根据用户输入识别：

- 内容大类。
- 小分类。
- 受众频向。
- 题材、情节、情绪、时空背景。
- 总集数、单集时长或 TVC 时长。
- 平台和投放目标。

输出：

- 全剧/全片钩子策略。
- 钩子强度曲线。
- 每集或每段节奏结构。

### 10.2 生成中：约束剧本

生成单集剧本或 TVC 脚本时，必须把钩子策略作为硬约束。

剧本生成不能只拿创意和题材，还应该带上：

- 当前集核心事件。
- 开场钩子。
- 中段升级点。
- 结尾悬念。
- 下一集承诺。
- 当前集在大钩子曲线中的位置。

TVC 生成应该带上：

- 时长。
- 目标人群。
- 核心痛点。
- 产品利益点。
- 情绪基调。
- 行动号召。

### 10.3 生成后：质检与重写

钩子 Agent 应检查：

- 前 3-5 秒是否有明确钩子。
- 中段是否有冲突或信息升级。
- 结尾是否有下一集点击理由。
- 是否出现假钩子，即看似悬念但不影响下一集。
- 是否符合男频/女频/双频策略。
- 是否符合题材、情节和情绪基调。
- 是否低于用户设置的强度阈值。

若不达标，应给出：

- 问题原因。
- 重写建议。
- 可一键替换的新版钩子。

### 10.4 每集审核：钩子 Agent + 编导 Agent + 导演 Agent

剧本每集审核建议放在 Step 5 剧本编辑器之后、Step 6 分镜生成之前。

审核流程：

```text
生成单集剧本
→ 钩子 Agent 审核：开场、结尾、承接、追更冲动
→ 编导 Agent 审核：剧情逻辑、人物动机、冲突升级、情绪节奏、台词
→ 导演 Agent 审核：画面表现、场景可拍性、镜头节奏、AI 生产难度
→ 输出审核报告
→ 用户选择一键优化 / 局部修改 / 通过进入分镜
```

三类 Agent 的分工：

| Agent | 核心目标 | 主要审核项 |
| --- | --- | --- |
| 钩子 Agent | 让用户继续看 | 前 3-5 秒钩子、集末悬念、上一集承接、下一集承诺、假钩子识别 |
| 编导 Agent | 让故事成立 | 核心事件、人物动机、人设一致性、冲突升级、情绪起伏、台词节奏 |
| 导演 Agent | 让画面可生产 | 场景数量、镜头表达、视觉冲击点、AI 生成难度、分镜拆解可行性 |

### 10.5 编导 Agent 审核标准

编导 Agent 主要判断这一集是不是“好看且成立”：

- 本集核心事件是否清楚。
- 人物行为是否符合人设。
- 上一集承诺是否得到兑现。
- 冲突是否升级，而不是原地重复。
- 情绪是否有起伏。
- 台词是否符合人物身份和短剧/漫剧节奏。
- 本集是否制造了合理的新问题。
- 男频、女频、双频策略是否匹配。
- 题材、情节和情绪基调是否统一。

### 10.6 导演 Agent 审核标准

导演 Agent 主要判断这一集是不是“能拍、能拆、能 AI 生产”：

- 场景数量是否过多。
- 是否有不适合 AI 生成的复杂群戏、复杂打斗或模糊动作。
- 关键钩子是否有清晰画面承载。
- 是否有强视觉瞬间，如特写、反应、揭示、动作停顿、信息反转。
- 镜头节奏是否适合单集时长。
- 是否能拆成分镜脚本、图片 Prompt、视频 Prompt 和配音字幕。
- 生产成本是否过高，是否需要压缩场景或角色数量。

### 10.7 审核结果处理原则

不建议让多个 Agent 直接连续改正文，否则容易越改越乱。推荐机制：

```text
Agent 先输出审核意见
→ 用户确认优化范围
→ 系统生成修改方案
→ 用户选择应用到正文
```

关键钩子、核心台词、关键反转、人设设定应支持锁定。锁定内容不得被一键优化覆盖。

## 14. 评分规则建议

钩子强度可采用 1-5 星或 0-1 分。

建议前端展示用星级，后端存储用 0-1 分。

| 星级 | 分数 | 含义 |
| --- | --- | --- |
| ★★★★★ | 0.85-1.00 | 强钩子，用户有强烈继续观看/点击冲动 |
| ★★★★☆ | 0.70-0.84 | 有吸引力，但仍可增强 |
| ★★★☆☆ | 0.50-0.69 | 普通钩子，能看但粘性一般 |
| ★★☆☆☆ | 0.30-0.49 | 弱钩子，缺乏紧迫感 |
| ★☆☆☆☆ | 0.00-0.29 | 基本无钩子 |

评估维度：

- 冲突是否明确。
- 信息差是否成立。
- 情绪是否有推进。
- 是否有兑现和新问题。
- 是否承接上一集。
- 是否制造下一集点击理由。
- 是否匹配受众和题材。
- 是否匹配时长。

## 16. 分阶段落地建议

### 阶段一：补齐剧本钩子结构

- 分集大纲输出从 `openingHook/closingHook` 升级为 `segments + nextEpisodePromise`。
- 单集剧本生成时传入当前集钩子结构。
- 增加钩子强度评分。

### 阶段二：加入用户可编辑曲线

- 前端增加钩子曲线编辑器。
- 支持默认模板和用户自定义模板。
- 支持保存用户习惯。

### 阶段三：支持 TVC 钩子 Agent

- 增加 TVC 大类入口。
- 支持用户选择 TVC 时长。
- 生成分秒级 TVC 钩子结构。

### 阶段四：增加每集多 Agent 审核闭环

- 在 Step 5 剧本编辑器中增加每集审核面板。
- 接入钩子 Agent、编导 Agent、导演 Agent。
- 生成结构化审核报告。
- 支持锁定关键内容、一键优化、局部修改和审核通过。

### 阶段五：Agent 质检与重写

- 检测弱钩子、假钩子、断裂承接。
- 支持一键重写。
- 支持按男频/女频/双频和题材规则优化。

### 阶段六：与分镜和画布生产联动

- 导演 Agent 的画面建议进入分镜生成。
- 将复杂场景、复杂动作、群戏风险提示给用户。
- 将强视觉钩子转为分镜重点镜头和图片/视频 Prompt。

## 17. 总结

钩子 Agent 的核心不是“生成几句吸引人的话”，而是控制内容结构。

剧本类：

```text
大钩子负责长期追更。
单集钩子负责当集看完。
承接钩子负责下一集点击。
```

TVC 类：

```text
注意力钩子负责停留。
痛点/利益钩子负责理解。
品牌/产品钩子负责记忆。
行动钩子负责转化。
```

最终产品应支持：

- 系统默认策略。
- 用户自定义策略。
- 按分类、标签、长度自动生成钩子曲线。
- 在剧本/TVC 生成前、中、后全流程约束和优化钩子。
- 在每集进入分镜前，通过钩子 Agent、编导 Agent、导演 Agent 进行联合审核，保证内容既有追更力，也能成立和生产。
