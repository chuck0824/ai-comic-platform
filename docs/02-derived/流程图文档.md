# AI漫剧与视频内容工业化生产工作台 · 流程图文档

> 基于《用户端产品功能设计.md》v0.7+《后端产品功能设计_V1.5.md》+《AI漫剧与视频内容工业化生产工作台 PRD V1.5》绘制  
> V1.3新增：画布多节点类型增强、下游菜单、多副本并行生成、Omni-Reference视频引擎、Agent画布联动、SOP质检流程  
> V1.5修订：产品定位升级为 AI 视频工业化生产工作台，主流程从静态画布展示升级为”项目 -> 剧本/想法 -> 分镜拆解 -> 资产沉淀 -> 批量生图/视频 -> 质检与采用版本 -> 素材包导出 -> 工作流复用”的可生产闭环。平台不提供视频剪辑、视频合成或多轨时间轴。
> 剧本创作修订：剧本模块改为”源头小说/故事文本 → 改编脚本 → 可选分镜生产”三层资产架构；AI生成或AI编辑后，用户仍可对单章正文继续修改和版本化。
> V1.7更新：新增统一任务事件中心、资产工作台、企业工作台、Agent配置中心、独立空白画布创建、生产SOP完成共6个superpowers流程图；补全脚本创作、分镜、画布、Agent会话、后端Outbox/TaskEventStore/CommandRouter等已有流程。
> **V1.8更新 `[superpowers 更新 V1.8]`**：新增 Canvas 生产内核流程（双模式/ShotWorkUnit 5-Gate/CapabilityRequest 管线/DirectorScene 冻结/迁移/交付打包）；节点类型 11→6 收缩；compose/export 流程标注废弃；音频截取/变速流程标注废弃。详见 `canvas-production-kernel-completion-design.md`。
> 文档类型：流程图合集（用户流程图 + 用户旅程图 + 页面跳转图 + 状态流转图 + 产品流程图 + 后端流程图）

### 13. 资产成熟度L0-L4升级流程

```
┌─────────────────────────────────────────────────────────────────┐
│                   资产成熟度升级路径 (L0 → L4)                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  L0: 无资产                                                      │
│  │    · 只有角色名字+一句话描述                                   │
│  │    · 使用文字临时锚点                                          │
│  │    ↓ AI从剧本自动提取角色/场景描述                              │
│  │                                                              │
│  L1: 有文字描述                                                   │
│  │    · 生成临时 Character_ID / Location_ID                      │
│  │    · 长锚点+短锚点文本                                         │
│  │    ↓ 用户/AI首次生成参考图/音频                                │
│  │                                                              │
│  L2: 有参考图/参考音频                                            │
│  │    · 建立候选 Face_ID / Voice_ID                              │
│  │    · 可进入画布测试生成                                        │
│  │    ↓ 用户确认审核通过                                          │
│  │                                                              │
│  L3: 已审核资产 ──────────────────────────┐                      │
│  │    · 可进入批量生产                     │                      │

│  │    ↓ 用户手动锁定                       │                      │
│  │                                         │                     │
│  L4: 锁定资产 ◄── 修改需触发连续性审计 ────┘                      │
│       · 仅对应负责人可解锁                                        │
│       · 解锁后降为L3，修改后需重新审核                             │
│       · 批量生产中强制保持L4                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

### Workspace 切换流程

```
用户登录(8080)
    │
    ▼
JWT 解析 → derive personal_uid
    │
    ▼
GET /api/v1/enterprise/context (X-Workspace-Id: personal_{uid})
    │
    ├── 成功 → 加载个人空间
    │
    └── 用户点击 Workspace 切换器
            │
            ▼
        GET 3001 /api/aicp/workspaces（列出可用 Workspace）
            │
            ├── 个人空间
            └── 企业空间（ent_xxx）
                    │
                    ▼
                GET 3001 /api/aicp/workspaces/{id}/membership
                    │
                    ├── 成功 → commitWorkspaceSelection()
                    │         │
                    │         ├── 清理旧 Workspace 缓存
                    │         ├── 设置 X-Workspace-Id = ent_xxx
                    │         └── 重载页面 → EnterpriseShell
                    │
                    └── 失败 → 保留旧 Workspace
                              └── Membership 失效 → fallbackToPersonal()
```

### 企业采购 → 审批 → 付款流程

```
成员提交采购申请
    │
    ▼
PurchaseApprovalService.submit()
    ├── 校验 trade.purchase.request + 对象范围
    ├── budgetService.reserve() ← 原子预占（条件SQL + row_version）
    ├── 创建 PurchaseRequest (PENDING_APPROVAL)
    ├── 创建 TradeOrder (PENDING_APPROVAL)
    └── 发射 TradeOutboxEvent → ApprovalProjector
            │
            ▼
        enterprise_approval_items (status=PENDING)
            │
            ▼
审批人查看统一审批收件箱
    ├── 查看预算摘要 + 共享余额 + 授权条款
    ├── 批准 → ApprovalCommandRouter
    │         ├── 回源读 PurchaseRequest
    │         ├── 鉴权 WorkspaceContext.canAccess()
    │         ├── purchaseApprovalService.approve()
    │         ├── TradeOrder → PENDING_PAYMENT（不自动扣款）
    │         └── 发射 Outbox → projection updated
    │
    └── 驳回 → budgetService.release() ← 释放预占
              └── TradeOrder → REJECTED

申请人/付款人确认付款
    │
    ▼
OrderService.pay()
    ├── walletClient.purchase() → 3001 钱包扣款
    ├── 成功 → budgetService.consume() ← reserved → consumed
    └── 失败 → 保留 PAYMENT_FAILED，按原订单号查单
```

### 项目导出审批流程

```
成员提交导出申请（固定项目版本）
    │
    ▼

    ├── 创建 ProjectExportRequest (PENDING)

    ▼
