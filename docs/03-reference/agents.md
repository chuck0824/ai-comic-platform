| 📊 **对标分析** | 与竞品对比，指出差距和机会 | `@产品专家 对比LibTV/Nody/NeoWOW，我们的画布引擎差在哪里` |
| 🔒 **安全检查** | 扫描硬编码凭据、认证漏洞 | `@产品专家 全面安全审查` |

### 审查维度

每次审查自动覆盖以下维度：

```
1. 功能完整性  → 对照 V1.5 PRD，检查缺失功能
2. 生产闭环    → 项目、画布、节点、分镜、资产、生成、时间线、导出是否闭环
3. 交互一致性  → 前后端 API 路径是否对齐
4. new-api集成 → LLM/图片/视频/音频/Agent 调用是否全部走 AI Router -> new-api
5. 商业化能力  → 算力预估、扣费、任务成本、资产复用、模板/Skill沉淀是否具备
6. 代码质量    → bug、性能、安全隐患
7. 竞品对标    → 与 LibTV/Nody/NeoWOW/即梦AI 对比
```

```bash

/product-review
```

