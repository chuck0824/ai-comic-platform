# Canvas 设计文档阅读器设计

> 日期：2026-07-05
> 状态：设计已确认，待实现
> 展示目标：`http://localhost:61300/`
> 内容来源：`docs/superpowers/specs/2026-07-05-canvas-production-kernel-completion-design.md`

## 1. 目标

将 Canvas 生产内核完整设计从原始 Markdown 文本展示升级为本地文档站，使产品、研发和测试能够持续阅读、搜索、定位和评审 19 章技术方案。

阅读器只负责展示，不修改内容源，不引入项目运行时依赖，不将临时展示代码并入业务前端。

## 2. 页面结构

采用三栏文档站布局：

- 顶部工具栏：文档标题、全文搜索、匹配跳转、阅读进度、主题切换；
- 左侧导航：第 1–19 章全文目录；
- 中间正文：完整语义化文档内容；
- 右侧导航：当前一级章节下的二级和三级标题；
- 浮动操作：返回顶部。

窄屏下折叠左右导航，正文保持单栏阅读。

## 3. 内容渲染

页面生成时将已提交 Markdown 完整嵌入本地 HTML。浏览器端无外部依赖地转换以下结构：

- 一级至三级标题和稳定锚点；
- 段落、无序列表和有序列表；
- 引用块；
- 围栏代码块和行内代码；
- Markdown 表格；
- 链接和水平分隔线。

表格在窄视口内使用横向滚动，代码块保留换行并提供复制按钮。渲染失败时显示原始 Markdown 和错误提示，保证内容仍可读取。

## 4. 交互

- 目录点击平滑滚动到稳定锚点；
- 滚动时高亮当前一级章节并更新右侧章节导航；
- 阅读进度按正文滚动范围计算；
- 搜索展示匹配数，并支持上一项、下一项；
- 搜索匹配在正文内高亮，清空后恢复原内容；
- 明暗主题保存在浏览器本地状态；
- 返回顶部按钮只在离开首屏后显示。

## 5. 数据流和边界

```text
已提交 Markdown
→ 本地页面生成时 HTML 转义并嵌入
→ 浏览器端 Markdown 解析
→ 语义化正文
→ 目录、搜索索引和滚动观察器
```

页面不向外部服务上传文档，不通过 CDN 加载解析器、字体或脚本。展示页变化不修改 Markdown 事实源。

## 6. 错误处理

- Markdown 解析异常：回退到转义后的原文；
- 单个表格或代码块解析失败：只回退该区块，不阻断其余正文；
- 浏览器不支持滚动观察器：目录仍可点击，当前章节高亮降级；
- 本地存储不可用：主题切换只在当前页面会话生效；
- 搜索无匹配：显示“0 项”，不改变正文位置。

## 7. 验收

- 页面包含文档开头、第 19 章和最后一句，全文没有截断；
- 左侧存在 19 个一级章节锚点；
- 标题、列表、引用、代码和表格不显示 Markdown 控制符；
- 搜索能够定位至少一个中文词和一个英文标识符；
- 目录、上一匹配、下一匹配、主题切换和返回顶部可用；
- 1280px 桌面视口三栏不遮挡正文；
- 窄屏视口正文可读，表格不撑破页面；
- 页面不产生控制台错误，不发起外部网络请求。
