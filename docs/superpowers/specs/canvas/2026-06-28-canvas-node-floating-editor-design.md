# 画布节点浮动编辑器改造设计

日期：2026-06-28

## 1. 背景

当前画布工作台在节点卡片、节点附近 Agent、右侧属性栏和底部生成栏中重复提供节点参数与执行入口。重复入口不仅占用画布空间，还存在参数不同步、默认值覆盖、模型选择未生效、脚本批量生成流程不一致等问题。

本设计采用已确认的方案 C：删除右侧属性栏和底部生成栏，将普通节点的参数编辑集中到节点附近的自适应浮动编辑器。脚本分镜表与导演台仍使用现有专业编辑器。

## 2. 目标

- 每个节点参数只存在一个可编辑入口。
- 浮动编辑器与当前选中节点保持明确的视觉和数据绑定。
- 删除右侧属性栏和底部生成栏，释放画布空间。
- 文本、图片、视频、音频使用统一浮动容器和各自的类型表单。
- 脚本与导演台仅在浮动编辑器中展示摘要和“打开专业编辑器”入口。
- 快速切换节点时不会发生跨节点数据写入。
- 所见参数与实际提交任务参数完全一致。

## 3. 非目标

- 不重做脚本分镜表内部结构。
- 不重做导演台内部布局。
- 不新增模型能力、计费规则或后端任务类型。
- 不改变节点连线、框选、拖拽和缩放的业务规则。
- 不在本次改造中建设完整任务中心；底部任务队列仅保留后续扩展位置，不显示空壳区域。

## 4. 总体交互

### 4.1 打开与关闭

- 单击节点：选中节点并打开该节点的浮动编辑器。
- 再次单击已选节点：保持编辑器打开，不重复初始化表单。
- 单击画布空白处或关闭按钮：关闭浮动编辑器并取消节点选择。
- 单击其他节点：先处理当前节点未保存草稿，再切换到新节点。
- 右键节点：仅打开结构操作菜单，不同时打开浮动编辑器。

### 4.2 定位策略

浮动编辑器渲染在屏幕坐标层，不参与画布缩放，保证文字和控件尺寸稳定。

定位优先级：

1. 节点右侧。
2. 右侧空间不足时放到节点左侧。
3. 左右均不足时放到节点下方。
4. 下方不足时放到节点上方。
5. 最终位置必须限制在画布可视区域内，并与边缘保留 16px 安全距离。

编辑器通过短连接线或小三角指向目标节点。拖动画布、移动节点、缩放或调整窗口大小时重新计算位置。重新定位只改变编辑器位置，不重置草稿。

### 4.3 尺寸与遮挡

- 默认宽度 440px，最小宽度 360px，最大宽度 520px。
- 默认最大高度为画布可视高度减 32px，内容区域内部滚动。
- 编辑器不得覆盖目标节点主体；无法完全避让其他节点时，以不遮挡目标节点和不越出视口为最高优先级。
- 面板头部支持拖动。用户手动拖动后，本次选中期间使用手动位置；切换节点后恢复自动定位。
- 面板可收起为仅含节点名称、保存状态和展开按钮的标题条。

## 5. 浮动编辑器结构

统一容器包含：

- 头部：节点图标、节点名称、保存状态、更多菜单、收起、关闭。
- 主体页签：按节点能力展示“内容/生成”“工具”“任务”，不展示空页签。
- 底部操作区：取消或重置、该节点的唯一主操作按钮。

“更多”菜单承载复制节点、复用节点、保存为资产和删除节点。画布右键菜单调用同一组动作处理函数，避免出现两套业务实现。

状态字段只读，由任务状态驱动；不允许用户手动把节点改为处理中、完成或失败。

## 6. 各节点设计

### 6.1 文本节点

- 节点卡片继续保留空态四种尝试动作和手动正文编辑。
- 浮动编辑器提供“内容”和“AI 助手”两个页签。
- “内容”展示正文编辑区，与节点卡片正文共享同一草稿，不创建第二份数据。
- “AI 助手”复用现有文本 Agent 的模型、指令、结果对比和应用流程。
- 取消独立的通用“生成 Prompt”输入框。
- 文生视频、图片反推提示词、文字生音乐继续创建预设节点组，不作为通用生成任务执行。

### 6.2 图片节点

- “生成”页签：提示词、参考图、图像模型、画面比例、生成数量、生成图片。
- “工具”页签：图像编辑、多图参考融合、全景模式、智能打光、高清放大等现有能力。
- “任务”页签：当前任务状态、失败原因、重试和最近结果。
- “发送到视频”在生成成功后显示为结果操作，不与“生成图片”并列。

### 6.3 视频节点

- “生成”页签：模式、提示词、首帧或参考素材、视频模型、画面比例、时长、生成数量、生成视频。
- “工具”页签：视频解析、高清、剪辑、延展、字幕、配音等已存在入口。
- “任务”页签：任务进度、失败原因、重试、采用版本和下载。
- 模式变化时动态显示必需字段；例如图生视频必须提供首帧。

### 6.4 音频节点

- “生成”页签：生成模式、文本或提示词、音频模型、音色、语速、时长、生成音频。
- “工具”页签：音频截取、变速、转字幕、分离音视频等已存在能力。
- “任务”页签：生成进度、试听、失败原因、重试和关联镜头/项目。
- 本次必须补齐右侧旧面板缺失的音频主生成按钮，确保删除底部生成栏后功能不丢失。

### 6.5 脚本节点

- 浮动编辑器只展示脚本摘要、镜头数量、完成状态和“打开专业编辑器”。
- “拆解剧本”可作为摘要区唯一的前置主操作。
- 合成提示词、镜头范围选择、批量生图和批量生视频统一在分镜专业编辑器中执行。
- 删除节点卡片上会绕过批量参数配置的直接生成路径。

### 6.6 导演台节点

- 浮动编辑器只展示场景元素数、机位数、截图数、画幅和“打开专业编辑器”。
- 机位截图、发送到画布和全景设置仅在导演台内部执行。
- 节点卡片不再提供脱离当前导演台上下文的截图与发送按钮。

## 7. 数据与状态设计

### 7.1 单一数据源

- 节点持久化数据仍存放在节点 `data/input_data` 中。
- 浮动编辑器草稿以 `nodeId` 为键管理，不使用跨节点共享的全局 Prompt 或生成配置。
- 每种节点的默认值只在节点创建时写入一次；打开编辑器不能用默认值覆盖已有字段。

### 7.2 保存规则

- 名称和普通参数采用节点级防抖保存。
- 防抖任务必须捕获创建时的 `nodeId`，不能在回调执行时读取当前选中节点。
- 切换或关闭节点时，已变更字段先立即提交；提交失败则保留草稿并阻止无提示丢失。
- 更新节点数据使用不可变合并，不直接修改传入的 props 对象。

### 7.3 执行规则

- 所有生成和工具操作通过统一动作入口执行，参数来自当前节点已验证的草稿快照。
- 提交载荷必须包含界面中实际选择的模型、比例、时长、数量和模式。
- 不再在执行函数中硬编码覆盖用户选择的模型。
- 多个视觉入口如右键菜单与更多菜单可以存在，但必须调用同一个动作处理函数。

## 8. 错误处理

- 必填参数缺失时在对应字段下显示错误，不提交任务。
- 模型不支持当前比例或时长时阻止提交并要求调整。
- 保存失败时头部显示“保存失败”，保留草稿并提供重试。
- 任务创建失败时保留全部参数，切换到“任务”页签展示错误。
- 节点已被其他操作删除时关闭面板并提示节点不存在。
- 面板定位计算异常时退化为画布右上角安全位置，不影响数据编辑。

## 9. 组件边界

建议拆分为以下单元：

- `NodeFloatingEditor`：统一容器、定位、拖动、收起和页签。
- `TextNodeEditor`：正文与文本 Agent。
- `ImageNodeEditor`：图片生成与工具。
- `VideoNodeEditor`：视频生成与工具。
- `AudioNodeEditor`：音频生成与工具。
- `ScriptNodeSummary`：脚本摘要与专业编辑器入口。
- `DirectorNodeSummary`：导演台摘要与专业编辑器入口。
- `useFloatingEditorPosition`：屏幕坐标、碰撞和视口约束。
- `useNodeDraft`：按节点隔离的草稿、验证、防抖保存和切换刷新。
- `nodeCapabilities`：节点字段、页签、默认值和动作能力的单一配置来源。

现有 `Canvas.vue` 负责选择节点、连接画布事件和调用节点动作，不再包含每种节点表单细节。

## 10. 迁移范围

- 删除 `Canvas.vue` 中的底部 `generator-panel` 及其全局状态和专用函数。
- 停止渲染旧 `NodePropertyPanel`，由浮动编辑器替代。
- 将现有 `CanvasNodeAgentBox` 的能力并入文本浮动编辑器，不保留第二个独立浮层。
- 保留并接入现有 `ShotTableEditor`、`BatchGeneratePanel` 和导演台覆盖层。
- 将节点卡片上的重复执行按钮收敛为预览、专业编辑器入口或结果操作。
- 不删除现有后端接口；前端统一调用路径后再评估无用接口。

## 11. 验收标准

1. 选中任意节点时，页面不存在右侧属性栏和底部生成栏。
2. 同一时间只显示一个节点浮动编辑器。
3. 浮动编辑器不覆盖目标节点且不会越出画布可视区域。
4. 缩放、平移、拖动节点和调整窗口后，面板仍正确关联目标节点。
5. 文本节点不存在正文、Agent 指令和通用 Prompt 三重输入冲突。
6. 图片、视频、音频的模型与参数提交值和界面选择完全一致。
7. 快速编辑节点 A 后切换节点 B，不会把 A 的字段写入 B。
8. 脚本批量生成必须经过镜头范围和参数确认。
9. 导演台截图与发送只在导演台内部执行。
10. 复制、复用、删除等动作从更多菜单和右键菜单触发时行为一致。
11. 所有现有节点创建、拖拽、连线和本地模式能力继续工作。

## 12. 测试策略

- 单元测试：浮动定位四向回退、视口约束、草稿按节点隔离、切换时刷新、防抖绑定节点 ID、参数验证。
- 组件测试：六类节点显示正确字段和主操作；无关字段不渲染；保存状态正确变化。
- 集成测试：图片、视频、音频提交载荷；文本 Agent 应用；脚本打开分镜和批量生成；导演台打开与截图回写。
- 回归测试：节点拖拽、缩放、平移、连线、右键菜单、本地模式和刷新恢复。
- 视觉测试：常用桌面尺寸下无越界；面板在节点靠近四个边缘时正确翻转。
