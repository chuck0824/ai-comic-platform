# 平台首页与画布项目中心设计

日期：2026-06-30
状态：已确认，已修订（2026-06-30 修订：补充迁移策略、快照差异、通知机制、空态设计等）

## 1. 背景

当前根路由直接进入画布编辑器，侧栏在"创作"和"管理"分组中重复出现两个"剧本创作"，已有 `Dashboard` 页面却没有形成真正的平台首页。画布也直接进入编辑器，没有跨项目的画布列表、明确的归属关系和历史恢复入口。

本设计建立统一平台首页，并补齐画布从内容项目、生产单元到具体编辑器的管理链路。

## 2. 已确认的产品决策

1. 首页定位为"创作启动为主，兼顾进行中工作、任务和轻量数据"的综合工作台。
2. 侧栏只保留一个"剧本创作"，位于"创作与生产"分组，点击进入内容项目列表。
3. 首页保留短剧、长篇和 TVC 三个独立创建入口，不合并为一个模糊的"开始创作"。
4. 首页以"内容创作 → 画布生产"为主链；仓库、交易、资产和任务是支撑层。
5. 一个内容项目可以包含多个画布，画布按集、章、TVC 版本或实验方案分别管理。
6. 同时提供全局"画布项目中心"和内容项目内"画布生产"页签，两处展示同一批画布数据，只是筛选上下文不同。
7. 不允许无归属空白画布。每个画布必须关联内容项目、生产单元和来源版本。

## 3. 信息架构

### 3.1 侧栏

```text
首页

创作与生产
├── 剧本创作
└── 画布工作台

内容与交易
├── 剧本仓库
├── 剧本交易市场
└── AI 资产市场

智能生产
├── Agent 会话
├── 资产生成历史
└── 任务监控

企业
├── 企业工作台
└── 生产 SOP
```

"画布工作台"（侧栏用户标签）对应全局画布项目中心页面（路由 `/canvas-projects`），两者指向同一功能入口。侧栏使用简短标签以适配导航宽度；页面标题使用完整名称"画布项目中心"。开发中组件名、路由名统一使用 `CanvasProjectCenter`。

### 3.2 路由建议

| 页面 | 路由 | 职责 |
|---|---|---|
| 平台首页 | `/` | 启动、续作、生产摘要、支撑模块入口 |
| 内容项目列表 | `/script-gen` | 管理短剧、长篇和 TVC 内容项目 |
| 新建内容项目 | `/script-gen/new?mode=...` | 按模式进入创建流程 |
| 全局画布项目中心 | `/canvas-projects` | 跨项目查找、筛选、恢复和管理画布 |
| 项目内画布生产 | `/script-gen/:projectId/workspace?tab=canvas` | 管理当前内容项目的生产单元与画布 |
| 具体画布编辑器 | `/canvas/:canvasProjectId` | 编辑节点、运行任务、合成与导出 |

根路由默认进入平台首页；`/dashboard` 重定向到 `/`。旧 `/canvas` 无 ID 入口迁移到 `/canvas-projects`，不得自动创建画布。

## 4. 平台首页

### 4.1 页面层级

首页从上到下包含：

1. 页面标题和用户状态。
2. 短剧、长篇、TVC 三个创建卡片。
3. "继续创作与生产"列表，展示最近 3–5 个需要继续处理的项目或生产单元。
4. "画布生产"摘要，展示进行中画布、生成任务和异常任务，并进入全局画布项目中心。
5. "内容与交易"入口：剧本仓库、剧本交易市场、AI 资产市场。
6. 轻量指标：内容项目数、本月锁稿数、生成资产数和待处理任务数。

首页不复制完整项目列表、任务中心或经营数据看板。

### 4.2 三种创作入口

| 入口 | 参数 | 目标 |
|---|---|---|
| 短剧创作 | `mode=short_drama` | 短剧创建流程 |
| 长篇创作 | `mode=long_form` | 长篇创建流程 |
| TVC 创作 | `mode=tvc` | TVC 创作流程 |

创建入口只负责启动。侧栏"剧本创作"进入内容项目列表，承担查找、筛选和项目管理。

### 4.3 继续工作列表

每行展示内容项目名称、模式、当前生产单元、当前阶段、进度或状态，以及唯一的上下文操作：

- 内容修订阶段：继续创作。
- 分镜阶段：进入分镜。
- 画布生产阶段：进入对应画布。
- 任务异常：查看任务详情。

**排序与筛选规则：**

- 按最后编辑时间（`updated_at`）倒序排列。
- 仅展示当前用户有读写权限的项目；不区分"创建者"与"协作者"。
- 已归档项目不出现；异常任务（生成失败、合成失败）优先于正常进行中项目，同优先级内按更新时间倒序。
- 若用户无可继续项目，列表区域展示引导文案"暂无进行中的创作"，下方提供"开始新创作"按钮跳转至对应创建卡片区域。

**列表数量：**

- 默认展示 5 条；不足 5 条时展示实际数量。
- 超过 5 条时提供"查看全部"链接，跳转至内容项目列表（`/script-gen`）。

**数据来源：**

列表由后端聚合查询返回，不通过前端多次请求拼装。后端查询范围：
- 用户有权限的内容项目及其当前阶段、生产单元。
- 用户有权限的画布及其状态、任务异常计数。

## 5. 画布数据与归属

### 5.1 业务层级

```text
内容项目
└── 生产单元（集 / 章 / TVC 版本）
    ├── 画布：正式生产方案
    ├── 画布：备选方案
    └── 画布：实验方案
```

画布是独立的生产工作区，但不是独立于内容项目的根对象。

### 5.2 画布必需关联

每个画布项目必须记录：

- `content_project_id`
- `production_unit_type`：`episode`、`chapter` 或 `tvc_variant`
- `production_unit_id`
- `source_content_version_id`
- `source_storyboard_version_id`
- `production_snapshot_id`：创建时生成的不可变来源快照
- `purpose`：`official`、`alternative` 或 `experiment`
- 名称、状态、负责人、缩略图、版本号、创建和更新时间

现有 `script_id + episode_index` 不足以支撑长篇、TVC、多版本和来源追溯，需要迁移为上述显式关联。迁移策略见第 9 节。

### 5.3 画布内部数据

节点、连线、分组、时间线、生成任务、生成资产、采用版本和导出记录继续归属于具体 `canvas_project`。删除画布时需按既定保留策略处理这些从属对象；已对外交付的导出记录不得静默删除。

### 5.4 来源快照

创建画布时固化以下内容：

- 内容版本（ID、哈希、标题、摘要）
- 分镜 Master 版本（ID、修订号、镜头数量、锁定状态）
- 项目插件包和资产成熟度
- 平台规则版本
- 画幅、分辨率、帧率等生产参数

上游正文或分镜发生变化时，不自动覆盖既有画布。系统展示差异，并允许用户创建新来源快照、复制为新画布方案，或保持当前画布不变。

### 5.5 来源快照差异对比

当画布的来源快照与上游当前版本存在差异时，系统提供逐项差异对比，包括：

**对比维度：**

| 维度 | 对比内容 | 差异类型 |
|---|---|---|
| 内容版本 | 标题、摘要、正文哈希、角色列表、场景数量 | 新增 / 修改 / 删除 |
| 分镜版本 | 修订号、镜头数量、镜头顺序、镜头参数 | 新增 / 删除 / 重排 / 参数变更 |
| 生产参数 | 画幅、分辨率、帧率、插件包版本 | 参数变更 |
| 平台规则 | 规则版本号、规则摘要 | 版本升级 |

**差异展示形式：**

- 以"变更摘要"优先展示：顶部汇总变更类型和数量（如"3 个镜头新增，1 个角色修改"）。
- 展开后逐项并排对比：左侧为快照值，右侧为当前上游值，差异行高亮。
- 分镜差异提供镜头顺序的可视化对比（缩略图网格，标注新增/删除/重排）。
- `CanvasSourceSnapshotDiff` 组件负责渲染此对比视图。

**差异严重程度：**

- 🔴 阻断性：内容版本不兼容（如正文结构重大变更）、分镜 Master 未锁定或被重置。此类差异下，建议创建新画布方案而非继续使用当前画布。
- 🟡 警告性：镜头新增/删除/重排、角色修改。当前画布可继续编辑，但生成结果可能与新版本不一致。
- 🔵 信息性：平台规则升级、插件包更新。不影响当前生产，可选择性采纳。

### 5.6 上游变更检测与通知

**检测时机：**

- 用户进入画布编辑器时，后端对比快照与当前上游版本，返回差异摘要。
- 全局画布项目中心和项目内画布生产页的列表接口返回 `has_upstream_changes` 标记（布尔值），用于在画布卡片上显示变更提示图标。
- 首页"继续工作"列表中，若画布有上游变更，在卡片副标题显示"上游已更新"标记。

**通知渠道：**

- 画布卡片上的视觉标记（黄色圆点 + tooltip"上游版本已变更"）。
- 进入画布编辑器时，以顶部横幅（banner）展示变更摘要，提供"查看差异"和"忽略"操作。
- 不在站外（邮件、推送）发送上游变更通知，避免干扰。

**幂等保证：**

快照内容由服务端根据当前上游状态构建，不使用客户端提交的值。幂等键由 `user_id + content_project_id + production_unit_id + source_content_version_id + source_storyboard_version_id + purpose` 组成。同一参数组合的重复创建请求返回已有画布（HTTP 200 + 已有画布数据），不创建重复记录。

## 6. 全局画布项目中心

### 6.1 页面职责

全局画布项目中心负责跨项目管理，提供：

- 状态筛选：全部、进行中、生成中、已完成、已归档。
- 模式筛选：短剧、长篇、TVC。
- 搜索：内容项目名、生产单元名、画布名。
- 排序：最近更新、创建时间、项目名称。
- 画布卡片：缩略图、名称、所属内容项目、生产单元、用途、状态、节点数、任务进度、更新时间和负责人。
- 操作：继续编辑、查看任务、查看画布、重命名、复制为新方案、移动到兼容的生产单元、归档和删除。

"移动生产单元"必须校验内容项目和来源版本兼容性，不允许跨用户或跨企业越权移动。

**搜索实现细节：**

- 搜索方式：模糊匹配（LIKE `%keyword%`），不要求中文分词。
- 搜索范围：同时匹配内容项目名称、生产单元名称（如"第 08 集"）和画布名称三个字段。
- 结果排序：搜索结果与筛选条件叠加使用；搜索时默认按相关度排序（名称精确匹配 > 名称前缀匹配 > 名称包含匹配），同相关度按更新时间倒序。
- 空搜索：关键词为空时不附加搜索条件，返回全部符合筛选条件的结果。
- 防抖：搜索输入 300ms 防抖后发起请求。

### 6.2 新建画布

点击"新建画布"打开创建弹窗或独立创建页，依次选择：

1. 所属内容项目。
2. 生产单元。
3. 来源内容版本。
4. 来源分镜 Master 版本。
5. 画布用途。
6. 画布名称和生产参数。

**生产准入检查：**

创建正式画布（`purpose=official`）前，系统必须验证：

- 分镜 Master 已锁定。
- 内容版本已审批通过。
- 生产单元下所有必需的镜头均已分配资产。
- 项目插件包和规则版本兼容当前平台版本。

准入检查为独立 API（`GET /api/v1/canvas/production-admission?contentProjectId=...&productionUnitId=...`），前端在用户选择来源后即可调用，提前展示准入状态。未通过准入时展示缺失项清单和补全入口（如"前往分镜锁定"、"前往资产分配"），不允许创建正式画布。备选方案（`alternative`）和实验方案（`experiment`）可放宽准入限制，但至少要求分镜 Master 存在。

只有来源满足画布生产准入时才能创建正式生产画布。未满足准入时允许返回补全分镜或资产，不创建半成品无归属画布。

## 7. 内容项目内"画布生产"页

项目工作区增加"画布生产"页签。左侧按生产单元列出集、章或 TVC 版本及画布数量；右侧展示当前生产单元的来源版本、生产准入状态和全部画布方案。

该页支持：

- 为当前生产单元创建画布。
- 查看正式、备选和实验方案。
- 进入具体画布编辑器。
- 对比画布来源快照。
- 查看上游变化提示。
- 复制方案、归档方案或设为正式方案。

项目内页面不展示其他内容项目的画布。

## 8. 关键流程

### 8.1 首页进入画布

```text
首页画布摘要
→ 全局画布项目中心
→ 选择画布
→ 具体画布编辑器
```

首页"继续创作与生产"若已经明确唯一画布，可直接进入对应编辑器。

### 8.2 内容项目进入画布

```text
内容项目工作区
→ 画布生产页签
→ 选择生产单元
→ 选择或创建画布
→ 具体画布编辑器
```

### 8.3 从分镜创建画布

```text
锁定分镜 Master
→ 生产准入检查
→ 确认来源版本和生产参数
→ 创建画布与不可变来源快照
→ 导入镜头和项目资产
→ 进入画布编辑器
```

重复提交使用幂等键，不能为同一确认操作创建多个重复画布。

### 8.4 面包屑导航

所有画布相关页面维护统一的面包屑，反映归属链路：

| 页面 | 面包屑 |
|---|---|
| 全局画布项目中心 | 首页 > 画布项目中心 |
| 项目内画布生产页 | 首页 > 剧本创作 > {项目名称} > 画布生产 |
| 画布编辑器 | 首页 > 剧本创作 > {项目名称} > 画布生产 > {画布名称} |

从全局画布中心直接进入编辑器时：

```
首页 > 画布项目中心 > {画布名称}
```

面包屑最后一级为当前页面（不可点击），前驱级别均为可点击链接。画布编辑器内的面包屑旁展示画布状态标签（如"生成中"、"已完成"）和用途标签（"正式"、"备选"、"实验"）。

## 9. 数据迁移策略

### 9.1 迁移范围

现有画布使用 `script_id + episode_index` 定位来源，缺乏显式的内容项目、生产单元和版本关联。迁移目标：每一条 `canvas_projects` 记录补齐 `content_project_id`、`production_unit_type`、`production_unit_id`、`source_content_version_id`、`source_storyboard_version_id` 和 `production_snapshot`。

### 9.2 迁移步骤

1. **新增列（DDL）**：在 `canvas_projects` 表中添加新列，旧列 `script_id` 和 `episode_index` 保留为 nullable 并标记为 `-- legacy` 注释。
2. **回填脚本**：执行数据回填脚本，对每条现有画布记录：
   - 通过 `script_id` 查找对应的内容项目和最新审批通过的内容版本。
   - 通过 `episode_index` 映射到生产单元（集）。
   - 查找对应的最新锁定分镜 Master 版本。
   - 构建 `production_snapshot` JSON（使用当前平台规则版本和默认生产参数）。
   - 设置 `purpose = 'official'`、`production_unit_type = 'episode'`。
3. **校验**：回填后运行校验脚本，确认 100% 记录的新列为 NOT NULL，且 `content_project_id + production_unit_id` 能关联到有效的内容项目和生产单元。
4. **切换读取**：前端和 API 切换到新字段读取，旧字段仅在回退时使用。
5. **清理（后续版本）**：确认新字段稳定运行一个版本后，在下一版本中删除旧列 `script_id` 和 `episode_index`。

### 9.3 回滚方案

若迁移后发现问题：
- 代码回滚到旧版本，继续使用 `script_id + episode_index` 读取（旧列保留且数据未删除）。
- 新列保留但不影响旧逻辑。
- 修复迁移脚本后重新执行回填。

### 9.4 无法自动追溯的画布

对于 `script_id` 或 `episode_index` 为 NULL 的历史空白画布（如有），迁移脚本将其标记为 `archived` 状态，不创建伪造的归属关联。此类画布在全局中心可见但只读，不可编辑或复制。

## 10. 状态与错误处理

画布状态建议统一为：

- `draft`：已创建，尚未开始生产。
- `editing`：正在编辑节点和参数。
- `generating`：存在运行中的生成任务。
- `composing`：正在合成。
- `completed`：已形成可交付结果。
- `archived`：已归档，只读或受限编辑。

错误处理规则：

- 来源版本不存在或无权限：阻止创建并返回版本选择。
- 分镜未锁定或生产准入不通过：展示缺失项，不创建正式画布。
- 画布不存在或无权限：返回画布项目中心并显示统一错误。
- 上游版本变化：展示差异，不自动覆盖。
- 画布保存失败：保留本地草稿和失败状态，允许重试。
- 任务失败：画布卡片和首页摘要显示异常数量，并进入任务详情。
- 网络超时或服务不可用：各页面模块独立降级——首页某区块加载失败时展示简化占位和重试按钮，不影响其他区块渲染。

## 11. 空态与边界条件

### 11.1 各页面空态

| 页面/区域 | 空态描述 | 操作引导 |
|---|---|---|
| 首页"继续工作"列表 | 插图 + "暂无进行中的创作" | "开始新创作"按钮跳转至创建卡片 |
| 首页"画布生产摘要" | "暂无画布生产任务" + 简介 | "前往画布项目中心"链接 |
| 首页轻量指标 | 各项显示 "0" | 无操作 |
| 全局画布项目中心 | 插图 + "暂无画布项目" | "新建画布"按钮（主操作）+ "前往剧本创作"链接（次操作） |
| 全局中心搜索无结果 | "未找到匹配'{关键词}'的画布" | "清除搜索条件"按钮 |
| 项目内画布生产页 | 按生产单元展示；无画布的单元显示 "0 个画布" + "创建画布"入口 |
| 画布编辑器（画布不存在） | 错误插图 + "画布不存在或已被删除" | "返回画布项目中心"链接 |

### 11.2 加载态

- 首页骨架屏：三个创建卡片区域使用占位卡片，列表区域使用 3 行占位行，指标区域使用 4 个占位数字块。
- 画布中心：首次加载使用 8 个画布卡片骨架；筛选/搜索触发的加载在列表上方显示进度条，不替换已有内容。
- 画布编辑器：加载时展示画布名称、面包屑骨架和画布区域居中加载动画。

### 11.3 边界条件

- 单用户拥有大量画布（>100）：分页默认 20 条/页，支持跳转至指定页。
- 内容项目被删除：其下所有画布标记为 `archived` 状态，保留数据但不可编辑。
- 生产单元被删除：其下画布保留，生产单元名称显示为"（已删除）"。
- 用户被移出企业：其个人画布保留；企业共享画布按企业权限策略处理（隐藏或只读）。

## 12. 组件与接口边界

建议新增或调整：

- `PlatformHome`：平台首页编排。
- `CanvasProjectCenter`：全局画布列表和筛选。
- `ProjectCanvasProduction`：内容项目内画布生产页。
- `CreateCanvasDialog`：带归属和来源校验的创建流程。
- `CanvasProjectCard`：全局和项目内复用的画布摘要卡片。
- `CanvasSourceSnapshotDiff`：来源快照与上游差异对比（差异摘要 + 逐项并排对比 + 分镜视觉对比）。
- `CanvasBreadcrumb`：画布页面统一面包屑组件。
- `ProductionAdmissionCheck`：生产准入状态展示组件。

接口至少包括：

- 查询当前用户可见画布，支持分页、搜索和筛选。
- 查询某内容项目或生产单元下的画布。
- 创建带完整归属和来源快照的画布（幂等）。
- 更新画布元数据和状态。
- 复制画布为新方案。
- 移动画布到兼容的生产单元。
- 归档、恢复和删除画布。
- 查询来源差异和生产准入结果。
- 查询首页"继续工作"聚合数据。

现有 `CanvasService#getUserProjects()` 可以作为列表能力的基础，但必须增加控制器接口、分页筛选、企业权限和内容项目关联。

## 13. 验收标准

1. 登录后根路由进入平台首页，不再自动进入或创建画布。
2. 侧栏只有一个"剧本创作"。
3. 首页分别展示短剧、长篇和 TVC 创建入口。
4. 侧栏"画布工作台"进入全局画布项目中心。
5. 用户能按状态、模式、项目和名称查找画布。
6. 内容项目内可以按生产单元查看全部画布方案。
7. 每个画布都能追溯到内容项目、生产单元、内容版本、分镜版本和来源快照。
8. 无法创建无归属画布。
9. 上游版本变化不会静默覆盖现有画布。
10. 首页画布摘要、全局画布中心和项目内画布页显示一致状态。
11. 用户可以从任一入口恢复到正确的具体画布编辑器。
12. 用户只能查看和操作自己或所属企业授权范围内的画布。
13. 现有画布数据迁移后归属完整，无数据丢失。
14. 各页面的空态、加载态和错误态均按设计实现。
15. 面包屑在所有画布相关页面正确反映归属链路。

## 14. 测试策略

- 路由测试：根路由、全局画布中心、项目内画布页和具体编辑器跳转。
- 权限测试：个人、企业成员、跨用户和跨企业访问隔离。
- 数据测试：短剧集、长篇章、TVC 版本的多画布归属。
- 创建测试：必填归属、来源快照、幂等创建和生产准入失败。
- 状态测试：编辑、生成、合成、完成和归档的列表一致性。
- 版本测试：上游变更后的差异提示、复制方案和不覆盖保证。
- 恢复测试：刷新、重新登录和从首页恢复到正确画布。
- 视觉测试：首页模块层级、画布卡片、空态、加载态和常用桌面尺寸。
- 迁移测试：旧数据回填完整性、校验脚本通过率、回滚后旧逻辑可用。
- E2E 测试：首页 → 创建画布 → 进入编辑器全流程；上游变更 → 差异提示 → 复制方案全流程。

## 15. 后续版本考虑

以下内容不在本次实施范围，标记为后续版本评估：

- **移动端适配**：当前设计面向桌面端（1280px+）。移动端画布编辑器交互复杂度高，需独立设计。
- **多人协作编辑**：同一画布同时被多人打开时的冲突检测和合并策略。
- **画布模板**：基于已完成画布创建可复用的生产模板。
- **批量操作**：批量归档、批量移动画布到同一生产单元。
- **画布版本分支**：从画布任意历史节点创建分支方案。
