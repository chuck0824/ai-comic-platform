# 平台首页与画布项目中心设计

日期：2026-06-30
状态：已确认，待实施计划

## 1. 背景

当前根路由直接进入画布编辑器，侧栏在“创作”和“管理”分组中重复出现两个“剧本创作”，已有 `Dashboard` 页面却没有形成真正的平台首页。画布也直接进入编辑器，没有跨项目的画布列表、明确的归属关系和历史恢复入口。

本设计建立统一平台首页，并补齐画布从内容项目、生产单元到具体编辑器的管理链路。

## 2. 已确认的产品决策

1. 首页定位为“创作启动为主，兼顾进行中工作、任务和轻量数据”的综合工作台。
2. 侧栏只保留一个“剧本创作”，位于“创作与生产”分组，点击进入内容项目列表。
3. 首页保留短剧、长篇和 TVC 三个独立创建入口，不合并为一个模糊的“开始创作”。
4. 首页以“内容创作 → 画布生产”为主链；仓库、交易、资产和任务是支撑层。
5. 一个内容项目可以包含多个画布，画布按集、章、TVC 版本或实验方案分别管理。
6. 同时提供全局“画布项目中心”和内容项目内“画布生产”页签，两处展示同一批画布数据，只是筛选上下文不同。
7. 不允许无归属空白画布。每个画布必须关联内容项目、生产单元和来源版本。

## 3. 信息架构

### 3.1 侧栏

```text
首页

创作与生产
├── 剧本创作
└── 画布工作台

内容与交易
├── 剧本仓库
├── 剧本交易市场
└── AI 资产市场

智能生产
├── Agent 会话
├── 资产生成历史
└── 任务监控

企业
├── 企业工作台
└── 生产 SOP
```

“画布工作台”实际进入全局画布项目中心，不直接进入某个具体编辑器。

### 3.2 路由建议

| 页面 | 路由 | 职责 |
|---|---|---|
| 平台首页 | `/` | 启动、续作、生产摘要、支撑模块入口 |
| 内容项目列表 | `/script-gen` | 管理短剧、长篇和 TVC 内容项目 |
| 新建内容项目 | `/script-gen/new?mode=...` | 按模式进入创建流程 |
| 全局画布项目中心 | `/canvas-projects` | 跨项目查找、筛选、恢复和管理画布 |
| 项目内画布生产 | `/script-gen/:projectId/workspace?tab=canvas` | 管理当前内容项目的生产单元与画布 |
| 具体画布编辑器 | `/canvas/:canvasProjectId` | 编辑节点、运行任务、合成与导出 |

根路由默认进入平台首页；`/dashboard` 重定向到 `/`。旧 `/canvas` 无 ID 入口迁移到 `/canvas-projects`，不得自动创建画布。

## 4. 平台首页

### 4.1 页面层级

首页从上到下包含：

1. 页面标题和用户状态。
2. 短剧、长篇、TVC 三个创建卡片。
3. “继续创作与生产”列表，展示最近 3–5 个需要继续处理的项目或生产单元。
4. “画布生产”摘要，展示进行中画布、生成任务和异常任务，并进入全局画布项目中心。
5. “内容与交易”入口：剧本仓库、剧本交易市场、AI 资产市场。
6. 轻量指标：内容项目数、本月锁稿数、生成资产数和待处理任务数。

首页不复制完整项目列表、任务中心或经营数据看板。

### 4.2 三种创作入口

| 入口 | 参数 | 目标 |
|---|---|---|
| 短剧创作 | `mode=short_drama` | 短剧创建流程 |
| 长篇创作 | `mode=long_form` | 长篇创建流程 |
| TVC 创作 | `mode=tvc` | TVC 创建流程 |

创建入口只负责启动。侧栏“剧本创作”进入内容项目列表，承担查找、筛选和项目管理。

### 4.3 继续工作列表

每行展示内容项目名称、模式、当前生产单元、当前阶段、进度或状态，以及唯一的上下文操作：

- 内容修订阶段：继续创作。
- 分镜阶段：进入分镜。
- 画布生产阶段：进入对应画布。
- 任务异常：查看任务详情。

## 5. 画布数据与归属

### 5.1 业务层级

```text
内容项目
└── 生产单元（集 / 章 / TVC 版本）
    ├── 画布：正式生产方案
    ├── 画布：备选方案
    └── 画布：实验方案
```

画布是独立的生产工作区，但不是独立于内容项目的根对象。

### 5.2 画布必需关联

每个画布项目必须记录：

- `content_project_id`
- `production_unit_type`：`episode`、`chapter` 或 `tvc_variant`
- `production_unit_id`
- `source_content_version_id`
- `source_storyboard_version_id`
- `production_snapshot_id`：创建时生成的不可变来源快照
- `purpose`：`official`、`alternative` 或 `experiment`
- 名称、状态、负责人、缩略图、版本号、创建和更新时间

现有 `script_id + episode_index` 不足以支撑长篇、TVC、多版本和来源追溯，需要迁移为上述显式关联。

### 5.3 画布内部数据

节点、连线、分组、时间线、生成任务、生成资产、采用版本和导出记录继续归属于具体 `canvas_project`。删除画布时需按既定保留策略处理这些从属对象；已对外交付的导出记录不得静默删除。

### 5.4 来源快照

创建画布时固化以下内容：

- 内容版本
- 分镜 Master 版本
- 项目插件包和资产成熟度
- 平台规则版本
- 画幅、分辨率、帧率等生产参数

上游正文或分镜发生变化时，不自动覆盖既有画布。系统展示差异，并允许用户创建新来源快照、复制为新画布方案，或保持当前画布不变。

## 6. 全局画布项目中心

### 6.1 页面职责

全局画布项目中心负责跨项目管理，提供：

- 状态筛选：全部、进行中、生成中、已完成、已归档。
- 模式筛选：短剧、长篇、TVC。
- 搜索：内容项目名、生产单元名、画布名。
- 排序：最近更新、创建时间、项目名称。
- 画布卡片：缩略图、名称、所属内容项目、生产单元、用途、状态、节点数、任务进度、更新时间和负责人。
- 操作：继续编辑、查看任务、查看画布、重命名、复制为新方案、移动到兼容的生产单元、归档和删除。

“移动生产单元”必须校验内容项目和来源版本兼容性，不允许跨用户或跨企业越权移动。

### 6.2 新建画布

点击“新建画布”打开创建弹窗或独立创建页，依次选择：

1. 所属内容项目。
2. 生产单元。
3. 来源内容版本。
4. 来源分镜 Master 版本。
5. 画布用途。
6. 画布名称和生产参数。

只有来源满足画布生产准入时才能创建正式生产画布。未满足准入时允许返回补全分镜或资产，不创建半成品无归属画布。

## 7. 内容项目内“画布生产”页

项目工作区增加“画布生产”页签。左侧按生产单元列出集、章或 TVC 版本及画布数量；右侧展示当前生产单元的来源版本、生产准入状态和全部画布方案。

该页支持：

- 为当前生产单元创建画布。
- 查看正式、备选和实验方案。
- 进入具体画布编辑器。
- 对比画布来源快照。
- 查看上游变化提示。
- 复制方案、归档方案或设为正式方案。

项目内页面不展示其他内容项目的画布。

## 8. 关键流程

### 8.1 首页进入画布

```text
首页画布摘要
→ 全局画布项目中心
→ 选择画布
→ 具体画布编辑器
```

首页“继续创作与生产”若已经明确唯一画布，可直接进入对应编辑器。

### 8.2 内容项目进入画布

```text
内容项目工作区
→ 画布生产页签
→ 选择生产单元
→ 选择或创建画布
→ 具体画布编辑器
```

### 8.3 从分镜创建画布

```text
锁定分镜 Master
→ 生产准入检查
→ 确认来源版本和生产参数
→ 创建画布与不可变来源快照
→ 导入镜头和项目资产
→ 进入画布编辑器
```

重复提交使用幂等键，不能为同一确认操作创建多个重复画布。

## 9. 状态与错误处理

画布状态建议统一为：

- `draft`：已创建，尚未开始生产。
- `editing`：正在编辑节点和参数。
- `generating`：存在运行中的生成任务。
- `composing`：正在合成。
- `completed`：已形成可交付结果。
- `archived`：已归档，只读或受限编辑。

错误处理规则：

- 来源版本不存在或无权限：阻止创建并返回版本选择。
- 分镜未锁定或生产准入不通过：展示缺失项，不创建正式画布。
- 画布不存在或无权限：返回画布项目中心并显示统一错误。
- 上游版本变化：展示差异，不自动覆盖。
- 画布保存失败：保留本地草稿和失败状态，允许重试。
- 任务失败：画布卡片和首页摘要显示异常数量，并进入任务详情。

## 10. 组件与接口边界

建议新增或调整：

- `PlatformHome`：平台首页编排。
- `CanvasProjectCenter`：全局画布列表和筛选。
- `ProjectCanvasProduction`：内容项目内画布生产页。
- `CreateCanvasDialog`：带归属和来源校验的创建流程。
- `CanvasProjectCard`：全局和项目内复用的画布摘要卡片。
- `CanvasSourceSnapshotDiff`：来源快照与上游差异。

接口至少包括：

- 查询当前用户可见画布，支持分页、搜索和筛选。
- 查询某内容项目或生产单元下的画布。
- 创建带完整归属和来源快照的画布。
- 更新画布元数据和状态。
- 复制画布为新方案。
- 归档、恢复和删除画布。
- 查询来源差异和生产准入结果。

现有 `CanvasService#getUserProjects()` 可以作为列表能力的基础，但必须增加控制器接口、分页筛选、企业权限和内容项目关联。

## 11. 验收标准

1. 登录后根路由进入平台首页，不再自动进入或创建画布。
2. 侧栏只有一个“剧本创作”。
3. 首页分别展示短剧、长篇和 TVC 创建入口。
4. 侧栏“画布工作台”进入全局画布项目中心。
5. 用户能按状态、模式、项目和名称查找画布。
6. 内容项目内可以按生产单元查看全部画布方案。
7. 每个画布都能追溯到内容项目、生产单元、内容版本、分镜版本和来源快照。
8. 无法创建无归属画布。
9. 上游版本变化不会静默覆盖现有画布。
10. 首页画布摘要、全局画布中心和项目内画布页显示一致状态。
11. 用户可以从任一入口恢复到正确的具体画布编辑器。
12. 用户只能查看和操作自己或所属企业授权范围内的画布。

## 12. 测试策略

- 路由测试：根路由、全局画布中心、项目内画布页和具体编辑器跳转。
- 权限测试：个人、企业成员、跨用户和跨企业访问隔离。
- 数据测试：短剧集、长篇章、TVC 版本的多画布归属。
- 创建测试：必填归属、来源快照、幂等创建和生产准入失败。
- 状态测试：编辑、生成、合成、完成和归档的列表一致性。
- 版本测试：上游变更后的差异提示、复制方案和不覆盖保证。
- 恢复测试：刷新、重新登录和从首页恢复到正确画布。
- 视觉测试：首页模块层级、画布卡片、空态、加载态和常用桌面尺寸。
