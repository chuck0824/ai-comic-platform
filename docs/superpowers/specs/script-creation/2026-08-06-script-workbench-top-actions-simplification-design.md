# 剧本创作工作台顶部功能入口精简设计

> 日期：2026-08-06  
> 状态：待用户评审  
> 适用范围：八阶段剧本创作工作台、剧本创作模块 PRD

## 1. 背景与问题

当前每个创作阶段顶部固定展示“任务中心、历史版本、重新生成、依赖影响、创作设置、返回首页”六个同等级按钮。该区域占用横向空间，按钮文字被迫换行，并将低频全局操作与高频阶段操作混在一起，弱化了当前阶段内容和底部确认按钮的视觉优先级。

## 2. 设计目标

- 顶部仅承载当前项目和阶段的必要上下文。
- 全局操作、阶段操作和异常操作分别放到符合使用时机的位置。
- 不删除原有能力，只调整入口层级和出现条件。
- 保持现有八阶段流转、任务、版本、重新生成和依赖失效逻辑不变。

## 3. 方案选择

采用“上下文入口分层”方案：移除顶部六按钮组，在页面不同区域按使用范围重新安置入口。

未采用方案：

- 仅缩小六个按钮：仍保留信息过载和同级竞争。
- 全部收进一个‘更多’菜单：虽然整洁，但会隐藏高频的当前阶段版本入口。

## 4. 页面调整

### 4.1 工作台顶部

保留：

- 项目名称。
- 当前阶段状态。
- 自动保存状态与更新时间。
- 当前阶段版本号。
- 单一“更多”菜单。

移除固定展示的六个功能按钮。

### 4.2 入口重新安置

| 原入口 | 新位置 | 显示规则 |
|---|---|---|
| 任务中心 | 左侧全局导航“剧本创作”旁的任务入口，或首页待办“查看全部” | 全局常驻，不在每个阶段重复 |
| 历史版本 | 当前阶段标题右侧“Vx · 历史版本” | 阶段内常驻，直接打开当前阶段版本历史 |
| 重新生成 | 当前阶段主要产物卡片的操作区 | 只有存在可重新生成的产物时显示 |
| 依赖影响 | 黄色 `STALE` 提示条及保存上游变更后的确认弹层 | 只有存在上游变更或下游过期时显示 |
| 创作设置 | 阶段 1 页面；其他阶段收进“更多 → 项目设置” | 阶段 1 直接编辑，阶段 2–8 为低频入口 |
| 返回首页 | 项目名称上方的“全部项目 / 当前项目”面包屑 | 全阶段常驻且不占用动作区 |

### 4.3 “更多”菜单

包含：项目设置、项目详情、归档项目。菜单不承载当前阶段的历史版本和重新生成，以免高频入口被过度隐藏。

## 5. 交互规则

- 点击面包屑“全部项目”返回默认首页；有未保存内容时先执行即时保存，保存失败则提示用户选择重试或放弃本地变更。
- 点击“Vx · 历史版本”打开现有版本历史弹层，默认筛选当前阶段。
- “重新生成”沿用现有配置弹层和保留旧版本策略。
- 仅当当前阶段或下游阶段状态为 `STALE` 时显示依赖影响提示；用户处理后提示消失。
- 阶段 2–8 从“更多”修改创作设置时，沿用下游影响确认流程，不静默覆盖。

## 6. 视觉与可访问性

- 顶部不再出现两行窄按钮，操作文字保持单行。
- 面包屑、阶段版本入口和“更多”按钮均使用原有组件颜色、圆角、字号与焦点样式。
- 菜单支持键盘打开、上下选择、Esc 关闭；焦点关闭后返回触发按钮。
- 条件化提示不能只依赖颜色，同时显示“需更新”文字和影响范围。

## 7. 测试与验收

- 八个阶段顶部均不存在原六按钮组。
- 每个阶段均可从标题区域进入当前阶段历史版本。
- 已生成产物的阶段显示“重新生成”，无产物阶段不显示。
- 非 `STALE` 状态不显示依赖影响；制造上游变更后出现提示并可处理。
- 阶段 1 可直接编辑创作设置；阶段 2–8 可从“更多”进入。
- 面包屑可返回首页，底部阶段确认和过渡页行为不受影响。
- 1280px 宽度下项目标题、状态、版本和“更多”均不换行、不裁切。
- 自动化测试、脚本语法检查和浏览器主流程回归全部通过。

## 8. PRD 同步范围

更新全局页面框架、版本入口、重新生成入口、下游影响提示、创作设置入口和返回首页规则；删除“六个按钮在每个阶段顶部常驻”的旧描述，保持后端接口与数据结构不变。
