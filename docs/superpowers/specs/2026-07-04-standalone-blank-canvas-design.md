# 独立空白画布创建设计

## 背景

现有画布编辑器只能通过 `/canvas/:projectId` 进入。全局入口先进入画布项目中心；当当前用户没有画布项目时，必须先创建画布。

当前创建表单强制要求内容项目、生产单元、内容版本和分镜版本。多数内容项目尚未产生完整上游版本，因此创建按钮保持禁用，用户无法进入已经存在的画布编辑器。准入检查还存在前后端查询参数命名不一致的问题，进一步产生“服务器繁忙”的误导提示。

## 目标

- 用户只填写画布名称，即可创建一个独立空白画布。
- 创建成功后直接进入现有画布编辑器。
- 内容项目、生产单元、内容版本和分镜版本均可在后续按需绑定或导入。
- 保留现有的项目绑定型画布以及其管理、编辑和生产能力。

## 非目标

- 不重写画布编辑器、节点、连线、时间线或素材功能。
- 不在本次改造中实现新的内容导入交互。
- 不自动创建隐藏的内容项目、生产单元或占位版本。
- 不放宽正式生成、合成或导出阶段对生产资料的要求。

## 方案

### 创建模型

沿用现有 `POST /api/v1/canvas/projects` 接口和 `canvas_projects` 表。

创建请求分为两种合法形态：

1. 独立空白画布：只要求 `name`、`purpose`、`owner_id` 和 `idempotency_key`。
2. 上游绑定画布：继续接受内容项目、生产单元、内容版本和分镜版本字段。

`content_project_id`、`production_unit_type`、`production_unit_id`、`source_content_version_id` 和 `source_storyboard_version_id` 在接口层允许为空。现有数据库列已经允许空值，不需要破坏性迁移。

空白画布使用 `purpose=experiment` 作为默认用途，表达“尚未进入正式生产”。后续绑定完整上游资料后，可由既有或后续的绑定操作升级为正式用途。

### 前端交互

“新建画布”对话框默认展示：

- 画布名称（必填）
- 用途（默认“实验方案”）
- 可展开的“关联内容项目（可选）”区域

不选择内容项目时，创建按钮只由画布名称决定。选择内容项目后，沿用现有的项目、生产单元和版本加载流程；缺少版本时显示明确说明，不再静默禁用。

创建成功后继续使用现有事件和路由，跳转到 `/canvas/{uuid}`。

### 后端行为

后端根据请求是否包含 `content_project_id` 区分创建形态：

- 空白画布：跳过生产准入检查，生成只包含画布基础配置的空白快照。
- 绑定画布：校验关联字段的一致性；正式方案继续执行生产准入检查。

画布记录仍以当前登录用户和工作空间为作用域，保持现有权限与幂等逻辑。

### 生产门禁

创建和编辑空白画布不要求上游资料。执行正式生成、合成或导出时，必须检查：

- 已关联内容项目和生产单元；
- 已关联内容版本和分镜版本；
- 相关版本满足生产状态要求。

本次实现只保证创建入口不再提前拦截；现有生产接口如果缺少统一门禁，则记录为后续独立任务，不在创建接口中伪造上游数据。

### 参数兼容

修复准入检查的查询参数契约。前端统一传后端当前声明的 `contentProjectId` 和 `productionUnitId`。其他列表查询参数暂不做无关重构。

### 错误处理

- 内容项目或版本加载失败时，在关联区域显示具体错误和重试入口。
- 空白画布创建失败时保留用户已输入的名称。
- 后端校验失败返回明确的 4xx 业务错误，不使用“服务器繁忙”表示参数缺失。
- 创建成功但路由跳转异常时，画布仍保存在项目中心，可再次进入。

## 测试

### 前端

- 空白画布草稿只填写名称即可提交。
- 选择关联模式后，缺少必要上游字段时不可提交并显示原因。
- 准入请求使用 `contentProjectId` 和 `productionUnitId`。
- 创建成功事件携带画布 UUID，并跳转到现有编辑器路由。

### 后端

- 最小请求能够创建空白画布，关联字段为空且状态为草稿。
- 重复幂等键返回同一画布。
- 完整绑定请求保持兼容。
- 正式绑定画布仍执行生产准入检查。
- 非法的部分绑定请求返回明确参数错误。

### 验收

1. 从侧边栏进入画布项目中心。
2. 点击“新建画布”，只填写名称。
3. 创建成功并进入 `/canvas/:projectId`。
4. 能在现有编辑器中创建和保存基础节点。
5. 返回项目中心后能再次进入该画布。

## 兼容性与风险

- 现有画布数据和绑定创建流程保持不变。
- 数据库关联列已可空，主要变化集中在 DTO 校验、服务分支和前端表单校验。
- 空白画布不能被误认为可正式生产；界面需要持续展示其“未绑定内容”的状态。
